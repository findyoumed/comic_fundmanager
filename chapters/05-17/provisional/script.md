# 05-17 임시 대본 — 채권운용전략 (1): 적극적인 전략

> **임시·미완성:** 지정 p1192 PDF에서 인쇄 pp.298–300(물리 pp.945–947)만 확인했다. 계획상 Topic 범위는 인쇄 pp.298–301이며 p.301이 빠져 있다. 아래 대본과 9개 임시 컷은 확인된 pp.298–300의 내용만 사용한다. 누락 쪽의 내용·결론·Topic 경계를 추정하지 않는다. p.301 확인 전에는 최종 JPG 내보내기나 회차 완료 처리를 하지 않는다.

## 학습 목표

교재가 제시한 적극적 채권운용전략의 종류와 수익률곡선타기·채권교체·스프레드·수익률곡선 전략의 조건을 구분한다. 각 전략은 교재의 이론적 설명이며 투자 권유가 아니다.

## 9컷 임시 대본

### 001 — 적극적 운용전략 지도
- 원전: 인쇄 p.298 / PDF 물리 p.945
- 장면: 누나가 전략 지도를 펼친다. 친구는 여러 전략이 하나의 방법인 줄 알고 헷갈린다.
- 대사: “교재는 적극적 채권운용전략을 이 다섯 가지로 나눠.”
- 표시: `금리예측전략(듀레이션조절)` / `채권교체전략` / `스프레드전략` / `수익률곡선타기전략` / `수익률곡선전략`

### 002 — 수익률곡선타기와 투자기간
- 원전: 인쇄 p.298 / PDF 물리 p.945
- 장면: 친구가 투자기간보다 만기가 긴 채권을 든다. 누나는 투자기간과 채권 만기를 서로 다른 눈금으로 보여 준다.
- 대사: “투자기간보다 만기가 긴 채권을 이용해. 보유 중 잔존만기가 짧아지며 수익률이 움직이는 효과를 활용하는 방식이야.”
- 표시: `투자기간 < 채권 만기` / `잔존만기 감소에 따른 수익률 변화 활용`
- 보조 대사: “교재 예처럼 3년물을 사서 1년 뒤 팔면 투자기간은 1년, 채권 만기는 3년이야.”
- 표시: `교재 예시: 투자기간 1년 / 채권 만기 3년`
- 주의: 예시임을 밝혀 원문에 없는 수치나 보유기간을 추가하지 않는다.

### 003 — 롤링효과와 숄더효과
- 원전: 인쇄 p.298 / PDF 물리 p.945
- 장면: 원문의 우상향 수익률곡선 위에서 장기채 위치가 곡선을 따라 이동하는 그림과 중·단기 구간의 두 점을 나란히 보여 준다.
- 대사: “장기채는 잔존만기가 짧아지면서 유동성 프리미엄만큼 수익률이 자연스럽게 내려가 자본수익이 생길 수 있어. 이게 롤링효과야.”
- 보조 대사: “중·단기채 구간의 자본수익 효과는 숄더효과라고 해.”
- 표시: `장기채: 롤링효과(ΔA)` / `중·단기채: 숄더효과(ΔB)`
- 주의: 두 효과의 차이는 원문 도식의 표기를 따르며, 보장된 수익으로 표현하지 않는다.

### 004 — 전제와 손실 가능성
- 원전: 인쇄 p.299 / PDF 물리 p.946
- 장면: 우상향 곡선이 유지되는 경우와 금리가 상승하는 경우를 분리해 보여 준다.
- 대사: “이 전략은 우상향 수익률곡선을 전제로 해. 금리가 상승하면 반대 결과로 손실이 생길 수도 있어.”
- 표시: `우상향 수익률곡선 전제` / `금리 상승 시 손실 가능`

### 005 — 채권교체전략
- 원전: 인쇄 p.299 / PDF 물리 p.946
- 장면: 같은 듀레이션의 두 채권을 비교한다. 친구가 교체 이유를 묻는다.
- 대사: “일시적인 불균형을 이용해 교체하거나, 같은 듀레이션에서 볼록성이 더 큰 채권으로 바꾸는 방법이 있어.”
- 표시: `동종채권교체` / `일시적 불균형 이용` / `같은 듀레이션에서 더 큰 볼록성의 채권으로 교체`

### 006 — Yield Give-Up / Pick-Up Swap
- 원전: 인쇄 p.299 / PDF 물리 p.946
- 장면: 불황기와 호황기 카드 아래 회사채·국채 교체 그림을 원문 도식 방향대로 배치한다.
- 대사: “교재는 불황기 스프레드 확대 상황의 Yield Give-Up Swap과, 호황기 스프레드 축소 상황의 Yield Pick-Up Swap을 구분해.”
- 표시: `이종채권교체` / `Yield Give-Up: 더 낮은 수익률 채권 매수; 불황기·스프레드 확대: 회사채 매도, 국채 매수` / `Yield Pick-Up: 더 높은 수익률 채권 매수; 호황기·스프레드 축소: 회사채 매수, 국채 매도`
- 주의: 시장 예측이나 실제 매매 권유가 아니라 원문 전략 도식의 요약이라고 표시한다.

### 007 — 스프레드전략
- 원전: 인쇄 p.299 / PDF 물리 p.946
- 장면: 넓어졌다가 정상 수준으로 돌아오는 스프레드, 좁아졌다가 정상 수준으로 돌아오는 스프레드를 각각 한 줄로 그린다.
- 대사: “스프레드가 일시적으로 넓어졌다면 축소 전략, 좁아졌다면 확대 전략을 세우고 정상 수준으로 돌아왔을 때 포지션을 정리하는 방식이야.”
- 표시: `일시적 확대 → 축소 전략` / `일시적 축소 → 확대 전략` / `정상 수준 회귀 시 청산`

### 008 — Barbell과 Bullet의 금리 예상
- 원전: 인쇄 p.300 / PDF 물리 p.947
- 장면: 단기·중기·장기 칸에 원문 표의 금리 예상 방향을 표시한다.
- 대사: “역나비형과 나비형은 수익률곡선에서 예상하는 방향이 서로 달라.”
- 표시: `Barbell(역나비형): 단기 금리↓ · 중기 금리↑ · 장기 금리↓` / `Bullet(나비형): 단기 금리↑ · 중기 금리↓ · 장기 금리↑`

### 009 — 가격 방향과 구성
- 원전: 인쇄 p.300 / PDF 물리 p.947
- 장면: 금리 예상 표 아래에 반대 방향의 채권가격 표시를 놓고 각 포트폴리오의 만기 구성을 비교한다.
- 대사: “교재 표는 금리 예상과 가격 방향, 실제로 담는 만기 구간을 한 세트로 비교해.”
- 표시: `Barbell: 단기 가격(+) · 중기(-) · 장기(+) / 단기·장기채 구성` / `Bullet: 단기 가격(-) · 중기(+) · 장기(-) / 중기채 구성`
- 마무리: “전략 이름만 외우지 말고, 원문 표의 금리 예상·가격 방향·구성을 함께 읽자.”
