# 05-05 기타의 합성채권(PB, 옵션부사채)

## 학습 목표

이익참가부사채(PB)와 옵션부사채의 특징을 알고, 수의상환채권(Callable Bond)과 수의상환청구채권(Putable Bond)의 옵션 행사자·행사 시기·가치 차이를 설명한다.

## 세로 스크롤 대본

### 05-05-001.png — 채권에 다른 권리를 더하다
- 원전: 인쇄 p.262 / PDF 물리 p.1120
- 화면: 일반 채권 위에 이익참가권 또는 조기상환 옵션이 더해진 두 구조.
- 여자 친구: “채권에 권리를 붙이면 투자자와 발행자의 선택이 달라지겠네.”

### 05-05-002.png — PB: 배당에도 참여하는 채권
- 원전: 인쇄 p.262 / PDF 물리 p.1120
- 이익참가부사채(PB, Participating Bond): 배당에도 참여할 권리가 부여된 사채.
- 누나: “약정된 채권의 권리에 더해 배당 참여권이 붙은 구조야.”
- 주의: 배당이 확정·보장된다고 표현하지 않는다.

### 05-05-003.png — 옵션부사채란
- 원전: 인쇄 p.262 / PDF 물리 p.1120
- 채권 발행 시 만기일 이전에 일정 조건으로 상환할 수 있는 옵션을 붙인 사채.
- 두 선택지: 발행자가 조기상환할 수 있는 콜옵션 / 투자자가 조기상환을 청구할 수 있는 풋옵션.

### 05-05-004.png — 콜옵션은 발행자의 권리
- 원전: 인쇄 p.262–263 / PDF 물리 pp.1120–1121
- 수의상환채권(Callable Bond): 콜옵션 보유자·행사자는 발행자.
- 금리가 하락할 때 발행자가 조기상환하고 더 낮은 금리로 새 채권을 발행해 조달금리를 낮추려 한다.
- 누나: “금리가 내려가면 발행자가 기존 고금리 채권을 갚고 낮은 금리로 다시 빌릴 수 있어.”

### 05-05-005.png — 풋옵션은 투자자의 권리
- 원전: 인쇄 pp.262–263 / PDF 물리 pp.1120–1121
- 수의상환청구채권(Putable Bond): 풋옵션 보유자·행사자는 투자자.
- 금리가 상승해 채권가격이 하락할 때 투자자는 약정 조건으로 조기상환을 청구해 추가 가격하락 위험을 줄일 수 있다.
- 주의: 조기상환 조건과 가격은 계약에 따른다.

### 05-05-006.png — 금리 방향과 행사 시점
- 원전: 인쇄 p.263 / PDF 물리 p.1121
- 콜옵션: 금리 하락기, 발행자가 행사. 풋옵션: 금리 상승기, 투자자가 행사.
- 남자 친구: “누가 옵션을 갖는지부터 보면 방향을 안 헷갈리겠네.”
- 화면: 두 흐름을 좌우로 비교한다.

### 05-05-007.png — 옵션은 채권가치에 더하거나 뺀다
- 원전: 인쇄 pp.262, 264 / PDF 물리 pp.1120, 1122
- 콜옵션부채권 가치 = 일반채권 가치 − 콜옵션 가치.
- 풋옵션부채권 가치 = 일반채권 가치 + 풋옵션 가치.
- 투자자 관점에서 콜옵션은 불리하고 풋옵션은 유리하다는 방향을 설명한다.

### 05-05-008.png — 발행금리에도 차이가 생긴다
- 원전: 인쇄 p.262 / PDF 물리 p.1120
- 교재의 발행금리 예시: 콜옵션부채권 6% > 일반사채 4% > 전환사채 2%.
- 콜옵션부채권은 투자자에게 불리하므로 투자자를 유인하려면 일반사채보다 높은 이자율을 제시할 수 있다.
- 주의: 이는 교재의 비교 예시이지 모든 발행의 보편적 금리 공식이 아니다.

### 05-05-009.png — 콜 리스크와 풋의 보호
- 원전: 인쇄 pp.263–264 / PDF 물리 pp.1121–1122
- 콜옵션부채권 투자자는 발행자의 조기상환으로 더 높은 이자 수취 기회가 끊길 수 있다(콜 리스크).
- 풋옵션부채권은 금리 상승 시 투자자가 매도·상환청구 선택권을 행사할 수 있어 일반채권보다 가치가 높을 수 있다.
- 가격-수익률 그래프는 콜옵션부 가격이 행사 가격 근처에서 제한되는 모습과 풋옵션부 가격 하방 보호를 단순화해 보여 준다.

### 05-05-010.png — 행사자를 기억하면 구분된다
- 원전: 인쇄 pp.262–264 / PDF 물리 pp.1120–1122
- PB: 배당 참여 권리.
- Callable: 콜옵션 / 발행자 행사 / 주로 금리 하락기 / 투자자에게 불리할 수 있음.
- Putable: 풋옵션 / 투자자 행사 / 주로 금리 상승기 / 투자자에게 유리할 수 있음.
- 마무리 대사: “옵션 이름보다 누가 행사하는지 먼저 보자.”
