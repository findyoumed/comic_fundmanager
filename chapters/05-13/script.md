# 05-13 볼록성(Convexity)

## 학습 목표

채권가격-수익률 곡선의 굽음이 듀레이션의 직선 근사 오차를 어떻게 보정하는지 설명하고, 원문 예제로 볼록성 항을 계산한다.

## 이야기 갈등

친구가 듀레이션으로 예상한 가격변동률을 실제 결과와 똑같다고 여기자, 하나가 곡선의 굽음과 선형 추정의 오차를 보여 주며 볼록성 항을 더한다.

## 원전 확인

p1192 PDF 물리 pp.928–933을 직접 렌더링해 확인했다. 볼록성은 수익률에 대한 채권가격 함수의 2차 도함수를 가격으로 나눈 값으로 설명된다. 듀레이션은 접선에 따른 선형 추정이며 볼록성 항은 1/2×Convexity×(Δr)^2이다. 전체 근사 가격변동률은 듀레이션 효과와 볼록성 효과의 합이다. 원문 예제에는 수정듀레이션 3.24, 수익률 2%p 하락, 가격상승률 7.32%, 볼록성 42가 나온다. 다른 예제는 볼록성 8.94와 Δr=-0.01에서 볼록성 효과 +0.0447%를 보인다. 인쇄 p.284에는 산술 오기가 있으므로 source_review.md를 확인하고 이미지에 오기 숫자를 옮기지 않는다.

### 05-13-004.png — 볼록성 보정 항
- 원전: 인쇄 pp.282–283 / PDF 물리 pp.929–930

### 05-13-005.png — 원문 예제에서 볼록성 풀기
- 원전: 인쇄 p.284 / PDF 물리 p.931
- 장면: 수익률 2%포인트 하락, 수정듀레이션 3.24, 가격 상승률 7.32%인 원문 예제에서 듀레이션 효과와 볼록성 효과를 분리해 볼록성을 푼다.
- 하나: “듀레이션 효과는 +6.48%, 남은 +0.84%가 볼록성 항이야.”
- 친구: “식에 대입하면 볼록성은 42네.”
- 표시 문구: Δr = -0.02
- 표시 문구: 수정듀레이션 = 3.24
- 표시 문구: 가격변동률 = +7.32%
- 표시 문구: 듀레이션 항 = -3.24×(-0.02) = +6.48%
- 표시 문구: 볼록성 항 = +0.84%
- 표시 문구: +0.0084 = 1/2×Convexity×0.0004
- 표시 문구: Convexity = 42

### 05-13-006.png — 원문 예제로 볼록성 구하기
- 원전: 인쇄 p.284 / PDF 물리 p.931
- 장면: 원문 예제 조건 카드 옆 계산 카드에 가중 현금흐름 합과 본문에 명시된 가격을 놓고 볼록성을 계산한다. 현금흐름 표 자체는 그리지 않는다.
- 하나: “가격은 9,502.63원이고, 원문이 제시한 볼록성은 약 8.94야.”
- 표시 문구: 액면 10,000원
- 표시 문구: 표면이율 8%
- 표시 문구: 잔존기간 3년
- 표시 문구: 연단위 후급
- 표시 문구: YTM 10%
- 표시 문구: 가격 P = 9,502.63원
- 표시 문구: 가중 현금흐름 합 = 84,951.96
- 표시 문구: 84,951.96 / 9,502.63 ≈ 8.94

### 05-13-008.png — 볼록성 항만 계산하기
- 원전: 인쇄 p.285 / PDF 물리 p.932
- 장면: 볼록성 8.94인 예에서 수익률 변화가 -1%포인트일 때 제곱항 계산을 단계별로 보여 준다.
- 친구: “변화가 -1%여도 제곱하면 양수네.”
- 표시 문구: Convexity = 8.94
- 표시 문구: Δr = -0.01
- 표시 문구: 1/2 × 8.94 × (-0.01)² = 0.000447
- 표시 문구: 볼록성 효과 ≈ +0.0447%
