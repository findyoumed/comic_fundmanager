# 04-03 원전 대조 기록

## 확인 원전

지정 p1192 PDF 물리 pp.855–856(인쇄 pp.208–209)을 확대해 직접 확인했다. 물리 p.855 푸터는 제3과목 제4장, Topic 03 「자산배분의 개념」을 표시한다. 물리 p.856에는 Topic 03의 보충문제와 해설이 이어진다. 목차 표에서 다음 Topic 04는 인쇄 p.210에서 시작한다.

| 컷 | 원전 근거 | 검토 결과 |
|---|---|---|
| 04-03-001 | p.208 자산배분 개념 | 위험 특성이 다른 여러 자산집단에 투자자금을 배분해 포트폴리오를 구성하는 의사결정으로 설명했다. |

| 04-03-004 | pp.208–209 전략·전술 배분 비교 | 장기 기준 설정과 중단기 조정을 구분하고 상하 관계를 표현했다. |

## 한계

수치와 계산은 p.209 예제의 가정에만 해당한다. 장면·색상·인물은 설명용 가상 표현이며 개인별 자산배분이나 수익을 권하지 않는다.
