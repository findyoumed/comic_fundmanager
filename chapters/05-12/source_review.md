# 05-12 원전 대조 기록

- 승인 원전: `../책_투자자산운용사_p1192.pdf`만 사용.
- 직접 렌더링·시각 확인: PDF 물리 pp.926–927, 교재 인쇄 pp.279–280.
- Topic 제목: 듀레이션으로 측정하는 가격변동률.
- 인쇄 p.279 핵심식: `ΔP/P = - Duration/(1+r) × Δr`; 수정듀레이션은 연단위 이자 지급 시 `Duration/(1+r)`, 연 m회 지급 시 `Duration/(1+r/m)`.
- 인쇄 p.279 핵심문제: 액면 10,000원, 표면이율 8%, 연단위 후급, YTM 10%, 가격 9,502.63원, Duration 2.78년. YTM이 8%로 하락하면 `-[2.78/(1+0.1)]×(-0.02)=+0.050545…`, 따라서 근사 가격변동률은 약 +5.05%(선택지 ②).
- 인쇄 p.279 분기 지급 예: Macaulay Duration 8.16, r=10%, m=4. `8.16/(1+0.10/4)=7.9609…`, 교재 표기 7.96.
- 인쇄 p.280 듀레이션 헤지 예: 현물 100억원×듀레이션 5.5, 선물 액면 1억원×듀레이션 10. `h=100×5.5/(1×10)=55`; 원문은 선물 55계약 매도로 표현.
- 인쇄 p.280 보충문제 해설은 채권가격 상승폭 순서가 듀레이션 순서와 같다고 설명하며 정답은 ④.
- 편집 주의: +5.05%는 듀레이션을 이용한 근사치다. 실제 가격변동이나 수익을 보장하는 수치로 쓰지 않는다. 원문 객관식 지문·선택지를 만화에 그대로 옮기지 않는다.
- 이미지 검수 진행: 001–007 PNG를 현재 확인했다. 001의 분모 `1+r`와 005–007의 부호·수치·근사 표현이 맞다. 기존 004는 원문에 없는 현금흐름 시간선으로 교정 대상으로 지정하고 v1을 `revisions/05-12-004-v1.png`에 보존했다. 새 004는 시간선을 제거하고 원문 조건 카드만 담아 교체·확인했다. 008–010 생성 후 전체 회차 PNG와 실제 690px JPG를 검토한다.
