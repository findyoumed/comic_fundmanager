# 05-12 듀레이션으로 측정하는 가격변동률

## 학습 목표

수정듀레이션과 금리변화로 채권의 근사 가격변동률을 구하고, 원문의 예제에서 금리 하락 시 가격 변화 방향과 크기를 계산한다. 보조 장면에서 듀레이션 헤지비율 예제를 정확히 읽는다.

## 이야기 갈등

금리가 10%에서 8%로 내려가면 채권 가격이 얼마나 움직일지 혼란스러운 친구에게, 수정듀레이션의 근사식으로 방향과 크기를 설명한다.

## 원전 확인

p1192 물리 pp.926–927 원문을 직접 확인했다. 가격변동률 ΔP/P = -Duration/(1+r) × Δr. 수정듀레이션은 연 이자 지급 때 Macaulay Duration/(1+r), 연 m회 지급 때 Duration/(1+r/m). 연단위가 아닌 예에서 Macaulay Duration 8.16, r=10%, m=4이면 수정듀레이션 7.96. Topic 12 핵심문제의 액면 10,000원, 표면이율 8%, 연단위 후급, YTM 10%, 가격 9,502.63원, Duration 2.78년. YTM 8%로 하락 시 근사 가격변동률 +5.05%, 정답 선택지 ②. p.927에는 듀레이션 헤지비율 h=(현물금액×현물듀레이션)/(선물금액×선물듀레이션), 100억원×5.5/(1억원×10)=55계약 매도 예제. 뒤 보충문제 가격상승률 순서는 듀레이션 순서와 같고 정답 ④. 핵심문제의 근사 계산과 실제 가격 변동을 혼동하지 않도록 설명한다.

- 표시 문구: 금리 변화와 채권가격 변화는 반대 방향

### 05-12-002.png — 수정듀레이션
- 원전: 인쇄 p.279 / PDF 물리 p.926
- 장면: 칠판에 수정듀레이션과 가격변동률 식을 쓴다.
- 하나: “가격 변화율을 듀레이션과 금리 변화로 근사할 수 있어.”
- 표시 문구: ΔP/P ≈ -[Duration/(1+r)]×Δr
- 표시 문구: 수정듀레이션 = Duration/(1+r) (연단위 지급)

### 05-12-003.png — 지급 주기가 연단위가 아니라면
- 원전: 인쇄 p.279 / PDF 물리 p.926
- 장면: 연 4회 지급 채권 카드를 추가해 분모에 지급횟수 m이 반영되는 모습을 보여 준다.
- 하나: “연 m회 지급이면 분모가 1+r/m으로 바뀌어.”
- 표시 문구: 수정듀레이션 = Duration/(1+r/m)
- 표시 문구: m: 연 이자지급횟수

### 05-12-005.png — 금리 변화 폭
- 원전: 인쇄 p.279 / PDF 물리 p.926
- 장면: 금리 눈금이 10%에서 8%로 내려가며 Δr을 표시한다.
- 하나: “변화 폭은 8%−10%, 즉 -2%포인트야.”
- 표시 문구: r: 10% → 8%
- 표시 문구: Δr = -2%p = -0.02

### 05-12-006.png — 수정듀레이션 계산
- 원전: 인쇄 p.279 / PDF 물리 p.926
- 장면: 2.78을 1.10으로 나누어 수정듀레이션을 표시한다.
- 친구: “2.78을 1.10으로 나누면 수정듀레이션이구나.”
- 표시 문구: 수정듀레이션 = 2.78/(1+0.10)

### 05-12-007.png — 변화 방향과 근삿값
- 원전: 인쇄 p.279 / PDF 물리 p.926
- 장면: 공식에 수정듀레이션과 -0.02를 대입한다. 두 음수 효과가 양의 가격변동률을 만든다.
- 하나: “마이너스에 금리 변화도 마이너스라 가격변동률은 플러스야.”
- 표시 문구: ΔP/P ≈ -[2.78/(1+0.10)]×(-0.02)
- 표시 문구: ≈ +0.0505 = +5.05%

### 05-12-008.png — 연 4회 지급 예
- 원전: 인쇄 p.279 / PDF 물리 p.926
- 장면: Macaulay Duration 8.16, YTM 10%, 연 4회 지급 조건을 식에 대입한다.
- 친구: “분모는 1+0.10/4로 계산하네.”
- 표시 문구: 수정듀레이션 = 8.16/(1+0.10/4) = 7.96

### 05-12-009.png — 듀레이션 헤지비율
- 원전: 인쇄 p.280 / PDF 물리 p.927
- 장면: 현물 포트폴리오 100억원, 듀레이션 5.5와 선물 액면 1억원, 듀레이션 10을 식에 넣는다.
- 하나: “헤지비율 식으로 필요한 선물 계약 수를 계산해 보자.”
- 표시 문구: h=(현물금액×현물듀레이션)/(선물금액×선물듀레이션)
- 표시 문구: 100억원×5.5/(1억원×10)=55계약
- 표시 문구: 교재 예제: 55계약 매도
