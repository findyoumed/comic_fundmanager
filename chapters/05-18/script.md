# 05-18 채권운용전략-(2) 소극적인 전략

## 학습 목표

다섯 소극적 전략을 구분하고 듀레이션 면역과 순자산가치 면역의 조건·계산·한계를 설명한다.

## 이야기 갈등

금리 예측에 지친 초보가 소극적 전략을 무관리·무위험으로 오해한다. 목표와 위험을 맞추는 과정으로 그 오해를 푼다.

### 05-18-008.png — 자본가치 변화 계산
- 원전: 인쇄p.303: p1476 PDF 물리p.1171, 원본0948.png
- 장면: 교재 수치 한 칸씩 계산. 자산200 부채120 DA4.5 DL3. 금리4%에서6%. 처음자본80에서근사손실10.38빼서69.62.
- 누나: “금리가 2%포인트 오르는 교재 예제로 계산해 보자.”
- 여자 친구: “변화율은 0.02를 넣고, 결과는 근삿값이네.”
- 표시 문구: 교재 예제: 자산 200 / 부채 120
- 표시 문구: 자산 듀레이션 4.5 / 부채 듀레이션 3
- 표시 문구: 금리 4% → 6%, Δr = 0.02
- 표시 문구: 초기 자본 = 200 − 120 = 80
- 표시 문구: ΔK ≈ −(200×4.5 − 120×3)÷1.04×0.02
- 표시 문구: ΔK ≈ −10.38
- 표시 문구: 변화 후 자본 ≈ 69.62
