# 04-02 원전 대조 기록

## 확인 원전

지정 p1192 PDF 물리 p.853(인쇄 p.206)과 물리 p.854(인쇄 p.207)를 직접 확대해 확인했다. 물리 p.853 푸터는 제3과목 제4장, Topic 02 「주식투자와 효율적 시장가설」을 표시한다. p.854에는 EMH 도식과 보충문제가 이어지며, 다음 Topic 시작점은 목차상 인쇄 p.208이다.

## 컷별 대조

| 컷 | 원전 근거 | 검토 결과 |
|---|---|---|
| 04-02-001 | p.206 주식투자의 특징 및 핵심문제 | 주식의 높은 기대수익률과 높은 위험을 함께 제시했다. 수익 실현이나 수익률 숫자는 만들지 않았다. |
| 04-02-002 | p.206 분산투자효과 기대 | 국내 주식·채권 상관계수가 0에 가깝고 해외주식과 국내주식 상관성이 낮다는 교재 서술을 반영했다. 그래프는 개념 설명 그림으로 표시했다. |
| 04-02-003 | p.206 국제적인 정합성 유지 | 과거 채권 중심에서 현재 주식 중심으로 변화했다는 책의 서술임을 화면에 명시했다. 모든 투자자·시장에 대한 보편 사실로 확대하지 않았다. |
| 04-02-004 | pp.206 효율적 시장가설 설명 | 정보가 가격에 반영된다는 전제를 소개하고 정보 범위별 세 형태로 이어지도록 구성했다. |
| 04-02-005 | p.206 효율적 시장가설 표 | 약형=과거 정보, 준강형=공개 정보, 강형=모든 정보의 순서와 범위를 확인했다. |
| 04-02-006 | p.206 EMH 표 및 중요 설명 | 약형의 기술적 분석, 준강형의 공개정보 기반 초과수익 한계, 강형 아래 액티브 전략 무용이라는 가설별 표현을 유지했다. 이를 실증적으로 절대 불가능하다는 주장으로 바꾸지 않았다. |
| 04-02-007 | p.207 EMH 보충문제와 해설 | 과거 정보에 근거한 초과수익 한계는 약형이며, 액티브 전체를 배제하는 결론은 강형을 신뢰할 때라는 해설을 두 칸 비교로 재구성했다. ‘원전 보충문제 기반 재구성’으로 표시했다. |
| 04-02-008 | pp.206–207 세 형태와 보충문제 해설 | 정보 범위를 약형→준강형→강형으로 정리하고 가설의 구분을 성과 보장과 분리했다. |

## 한계

모든 사실은 p1192 인쇄 pp.206–207의 설명에 한정한다. 차트·정보 카드·대화는 개념을 보이기 위한 가상 표현이며 실제 시장 데이터나 투자성과가 아니다.
