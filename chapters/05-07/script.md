# 05-07 유통시장(Secondary Market)

## 학습 목표

유통시장의 기능과 장내·장외 구조, IDM·IDB·PD의 역할을 구분하고 거래단위·결제·딜러 의무 수치를 교재 기준으로 해석한다.

## 이야기 갈등

만기 전에는 돈이 묶인다고 생각한 남자 친구가 채권을 되파는 길을 배우지만, 유동성이 원하는 가격이나 원금을 보장하지 않음을 깨닫는다.

## 원전 확인

2026-11-14 p1476 판본의 PDF 물리 pp.1127–1128을 시각 대조했다. 원전 표는 과거 시장 구분과 2026년 주석이 함께 실려 있어 거래단위·결제·PD 수치는 교재 학습 기준으로 표시한다. 원전 문제 선택지를 재현하지 않고 설명 자료로 각색한다.
