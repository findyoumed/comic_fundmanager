# 05-14 수익률곡선(Yield Curve)

## 원전 확인

p1192 PDF 물리 pp.934–936, 교재 인쇄 pp.287–289를 직접 시각 대조했다.

## 10컷 대본

### 001 수익률곡선이란
- 원전: 인쇄 p.287 / 물리 p.934
- 장면: 세 친구가 같은 그래프를 본다. 세로축은 채권수익률, 가로축은 잔존만기다.
- 대사: 수익률곡선은 만기별 수익률을 연결한 선이야.
- 표시: 세로축: 채권수익률, 가로축: 잔존만기, 기간별 수익률의 연결

### 002 같은 국채, 다른 만기
- 원전: 인쇄 p.287 / 물리 p.934
- 장면: 원문 그래프의 국채 점 세 개를 3년 3.7%, 4년 3.9%, 5년 4.0%로 읽는다.
- 대사: 같은 국채라도 만기에 따라 수익률이 다르네.
- 표시: 국채 3년: 3.7%, 국채 4년: 3.9%, 국채 5년: 4.0%

### 003 신용스프레드
- 원전: 인쇄 p.287 / 물리 p.934
- 장면: 5년 회사채 8.0%와 5년 국채 4.0%를 비교한다.
- 대사: 같은 5년 만기에서 회사채와 국채의 차이가 신용스프레드야.
- 표시: 5년 회사채 8.0%, 5년 국채 4.0%, 신용스프레드 = 8.0%−4.0% = 4.0%p

### 004 기간스프레드
- 원전: 인쇄 p.287 / 물리 p.934
- 장면: 회사채 곡선의 5년 8.0%와 4년 7.6%를 비교한다.
- 대사: 같은 회사채의 만기 차이를 비교하면 기간스프레드야.
- 표시: 회사채 5년: 8.0%, 회사채 4년: 7.6%, 기간스프레드 = 8.0%−7.6% = 0.4%p

### 005 두 스프레드의 기준
- 원전: 인쇄 p.287 / 물리 p.934
- 장면: 하나가 두 카드를 나란히 놓는다. 하나는 같은 만기의 발행자 차이, 다른 하나는 같은 발행자의 만기 차이다.
- 대사: 발행자 위험을 비교하면 신용, 만기를 비교하면 기간 구조야.
- 표시: 신용스프레드: 같은 만기, 다른 신용위험, 기간스프레드: 같은 발행자, 다른 만기

### 006 경기와 신용스프레드
- 원전: 인쇄 p.287 / 물리 p.934
- 장면: 경기불황과 자금경색 장면에서 회사채와 국채의 간격이 넓어진다.
- 대사: 원문은 신용스프레드가 경기불황에 더 확대된다고 설명해.
- 표시: 경기불황·자금경색, 신용스프레드 확대

### 007 수익률곡선의 네 형태
- 원전: 인쇄 p.288 / 물리 p.935
- 장면: 하나가 우상향, 우하향, 굴곡형(낙타형), 수평형을 네 개 그래프로 보여 준다.
- 대사: 수익률곡선은 네 가지 대표 형태로 나타날 수 있어.
- 표시: 우상향(상승형), 우하향(하강형), 굴곡형(낙타형), 수평형

### 008 형태가 담는 맥락
- 원전: 인쇄 pp.288–289 / 물리 pp.935–936
- 장면: 네 그래프 옆에 원문 설명을 조건부 카드로 요약한다.
- 대사: 곡선 형태는 정책과 시장 상황을 읽는 단서야.
- 표시: 우상향: 가장 일반적 형태, 우하향: 높은 금리 수준·긴축적 통화정책, 굴곡형: 일시적 위축·왜곡된 기간구조, 수평형: 수익률 예측이 어려운 경우

### 009 채권투자 위험 구분
- 원전: 인쇄 p.288 / 물리 p.935
- 장면: 위험 카드를 펼친다: 금리 변동, 구매력, 재투자, 채무불이행(신용), 중도상환(콜).
- 대사: 금리 외에도 물가와 발행자 행동 같은 위험이 있어.
- 표시: 이자율 변동위험, 구매력위험, 재투자위험, 채무불이행위험(신용위험), 중도상환위험(콜위험)

### 010 핵심 정리
- 원전: 인쇄 pp.287–289 / 물리 pp.934–936
- 장면: 세 친구가 그래프를 다시 보며 스프레드 정의와 곡선 형태, 위험을 요약한다.
- 대사: 만기와 발행자를 먼저 맞춰 비교하면 돼.
- 표시: 수익률곡선: 같은 신용구조의 만기별 수익률, 신용스프레드: 같은 만기의 발행자 차이, 기간스프레드: 같은 발행자의 만기 차이, 곡선은 시장 상황을 읽는 참고자료
