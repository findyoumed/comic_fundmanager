# 08-08 주요경제변수

## 학습 목표

GDP·GDI·GNI의 기준과 연결, 국민소득 3면 등가, 노동지표의 분모를 구분한다.

## 세로 스크롤 대본

### 08-08-001.png — 국내 생산과 국민 소득

남자 친구: 국내에서 만든 것과 우리 국민이 번 것은 늘 같은 값이야?

누나: GDP는 국내 생산자가 국내에서 만든 부가가치의 합이고, GNI는 국민이 생산활동에 참여해 받은 소득의 합이야. 해외에서 받은 소득과 국내에서 외국인에게 지급한 소득 차이가 둘을 갈라.

여자 친구: 국경 안의 생산과 국민에게 돌아가는 소득은 기준이 다르구나.

화면: 국내생산 GDP와 국민소득 GNI를 나란히 놓고 “장소 기준”과 “국민 기준”을 구분한다.

### 08-08-002.png — GDP에서 GNI까지

누나: 실질 기준에서는 먼저 실질GDP에 교역조건 변화에 따른 실질무역손익을 반영해 실질GDI를 구해.

남자 친구: 그리고 국외순수취요소소득을 더하면 실질GNI구나.

누나: 맞아. 명목 기준에서는 명목GDP에 명목 국외순수취요소소득을 더해 명목GNI를 구해.

화면: 정확한 흐름식 “실질GDP + 교역조건 변화에 따른 실질무역손익 = 실질GDI”, “실질GDI + 국외순수취요소소득 = 실질GNI”, “명목GDP + 명목 국외순수취요소소득 = 명목GNI”.

### 08-08-003.png — 생산·지출·분배는 세 관점

여자 친구: 같은 생산을 지출이나 소득 쪽에서 봐도 합계가 같아?

누나: 국민계정에서는 총생산 = 총지출 = 총분배야. 지출은 소비·투자·정부지출·순수출로, 분배는 임금·이자·지대·이윤으로 나눠 볼 수 있어.

화면: 큰 식 “Y = C + I + G + (X − M) = W + N + R + P”. 각 기호를 소비, 투자, 정부지출, 순수출, 임금, 이자, 지대, 기업이윤으로 붙인다.

### 08-08-004.png — 노동지표는 분모가 핵심

누나: 경제활동인구는 취업자와 실업자를 합한 인구야. 실업자는 일할 의사·능력이 있고 적극적으로 구직하는 사람이야.

남자 친구: 실업률은 실업자를 경제활동인구로 나누네.

여자 친구: 경제활동참가율은 경제활동인구를 생산가능인구로 나누고.

화면: 분류도와 식 “실업률 = 실업자 ÷ 경제활동인구 × 100”, “경제활동참가율 = 경제활동인구 ÷ 생산가능인구 × 100”. 분모를 색으로 강조한다.
