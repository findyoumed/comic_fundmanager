# 05-11 맥컬레이 듀레이션

## 학습 목표

맥컬레이 듀레이션을 현금흐름 현재가치의 가중평균 회수기간으로 설명하고, 교재 예제의 가중합·분모·절사 기준에 따라 계산한다.

## 이야기 갈등

만기 3년 채권의 듀레이션도 무조건 3년이라고 생각한 친구가 중간 쿠폰의 현재가치 가중을 계산한다.

## 원전 확인

2026-11-15 p1192 물리 pp.923–925를 확대 렌더로 직접 확인했다. 듀레이션은 미래 현금흐름 현재가치로 가중한 평균 회수기간이며 가격 민감도와 연관된다. 인쇄 p.276 핵심 예제는 액면 10,000원, 잔존 3년, 표면이율 6%, 연 1회 후급, YTM 4%다. 현금흐름 600, 600, 10,600원의 현재가치는 원전 표시대로 576.92, 554.73, 9,423.36원이고 합계 10,555.01원이다. t×현재가치 가중합은 29,956.46원이며 나누면 2.838년이다. 원전 지시대로 소수 둘째 자리 미만 절사하여 2.83년으로 표기한다(통상 반올림 결과와 구분). 계산 표는 설명용으로 재구성하고 원문 선택지를 옮기지 않는다.

### 05-11-001.png — 듀레이션은 만기와 같은 말일까?
- 원전: 인쇄 p.276 / PDF 물리 p.923
- 장면: 만기 3년 채권을 본 친구가 듀레이션도 3년이라고 적으려 하자, 누나가 중간 쿠폰 시점을 가리킨다.
- 남자 친구: “만기가 3년이면 듀레이션도 꼭 3년이지?”
- 누나: “중간 현금흐름의 현재가치까지 가중해서 계산해 봐.”
- 표시 문구: 만기: 마지막 지급 시점
- 표시 문구: 듀레이션: 현금흐름 현재가치 가중평균 시점

### 05-11-002.png — 현금흐름마다 시점이 달라
- 원전: 인쇄 p.276 / PDF 물리 p.923
- 장면: 1·2·3년 말에 받는 쿠폰과 마지막 원금을 서로 다른 시간 위치에 배치한다.
- 여자 친구: “언제 받는지와 오늘 가치가 얼마인지 둘 다 필요하네.”
- 표시 문구: t: 지급 시점
- 표시 문구: CFₜ: 시점 t의 현금흐름
- 표시 문구: 현재가치 = CFₜ ÷ (1+YTM)^t

### 05-11-003.png — 현재가치가 가중치가 돼
- 원전: 인쇄 p.276 / PDF 물리 p.923
- 장면: 각 지급 시점 t가 해당 현금흐름의 현재가치 비중으로 평균에 들어가는 도식.
- 누나: “각 지급 시점에 현재가치 비중을 곱해 평균을 내는 거야.”
- 표시 문구: D = Σ[t×CFₜ/(1+r)^t] ÷ Σ[CFₜ/(1+r)^t]
- 표시 문구: r: 만기수익률(YTM)
- 표시 문구: 분모 = 채권가격 P

### 05-11-004.png — 교재 예제의 조건
- 원전: 인쇄 p.276 / PDF 물리 p.923
- 장면: 계산 전 액면·쿠폰·잔존기간·YTM 네 조건을 확인한다.
- 남자 친구: “액면 1만 원, 표면이율 6%, 3년, YTM 4%네.”
- 표시 문구: 교재 예제
- 표시 문구: 액면 10,000원
- 표시 문구: 표면이율 6% · 잔존 3년
- 표시 문구: 연 1회 후급 · YTM 4%

### 05-11-005.png — 받는 현금흐름을 시간선에
- 원전: 인쇄 p.276 / PDF 물리 p.923
- 장면: 1·2년 말 쿠폰 600원, 3년 말 원금과 쿠폰 10,600원을 시간선에 배치한다.
- 여자 친구: “마지막에는 원금과 쿠폰을 함께 받아.”
- 표시 문구: 1년 말 CF₁ = 600원
- 표시 문구: 2년 말 CF₂ = 600원
- 표시 문구: 3년 말 CF₃ = 10,600원

### 05-11-006.png — 각 현금흐름을 현재가치로
- 원전: 인쇄 p.276 / PDF 물리 p.923
- 장면: 세 금액을 각각 YTM 4%와 시점에 따라 할인해 현재가치 카드로 바꾼다.
- 누나: “받는 시점이 늦을수록 할인 횟수가 늘어나.”
- 표시 문구: 1년: 600 ÷ 1.04 = 576.92원
- 표시 문구: 2년: 600 ÷ (1.04)^2 = 554.73원
- 표시 문구: 3년: 10,600 ÷ (1.04)^3 = 9,423.36원

### 05-11-007.png — 시점까지 곱해 가중합
- 원전: 인쇄 p.276 / PDF 물리 p.923
- 장면: 각 현재가치에 지급시점 1·2·3을 곱해 세 가중항을 만든다.
- 남자 친구: “현재가치만 더하는 게 아니라 각 시점도 곱하는구나.”
- 표시 문구: 1×576.92 = 576.92
- 표시 문구: 2×554.73 = 1,109.46
- 표시 문구: 3×9,423.36 = 28,270.08
- 표시 문구: 가중합 = 29,956.46원

### 05-11-008.png — 가중합을 가격으로 나누면
- 원전: 인쇄 p.276 / PDF 물리 p.923
- 장면: 가중합 29,956.46원을 현재가치 합계 10,555.01원으로 나누어 듀레이션을 구한다.
- 여자 친구: “현재가치 합으로 나누면 가중평균 시점이 돼.”
- 표시 문구: 현재가치 합계 = 10,555.01원
- 표시 문구: D = 29,956.46 ÷ 10,555.01
- 표시 문구: = 2.838…년

### 05-11-009.png — 이 문제는 둘째 자리 미만 절사
- 원전: 인쇄 p.276 / PDF 물리 p.923
- 장면: 2.838…년에서 둘째 자리 아래를 잘라 교재 답 2.83년을 표시하고, 반올림 2.84와 혼동하지 않도록 한다.
- 누나: “교재는 둘째 자리 미만 절사라서 2.83년이야.”
- 표시 문구: 계산값 2.838…년
- 표시 문구: 교재 기준: 소수 둘째 자리 미만 절사
- 표시 문구: 표기 = 2.83년
- 표시 문구: 일반 반올림과 구분

### 05-11-010.png — 듀레이션은 가중평균 회수기간
- 원전: 인쇄 pp.277–278 / PDF 물리 pp.924–925
- 장면: 쿠폰채의 중간 지급과 만기일시상환채의 단일 지급을 비교해 듀레이션과 만기의 관계를 요약한다.
- 여자 친구: “중간에 받는 쿠폰이 있으면 가중평균 회수기간은 만기보다 짧아지는구나.”
- 누나: “듀레이션은 민감도 지표이기도 하지만 실제 수익을 보장하진 않아.”
- 표시 문구: 이표채: 듀레이션 < 만기
- 표시 문구: 만기일시상환채: 듀레이션 = 만기
- 표시 문구: 현재가치 가중평균 회수기간
- 표시 문구: 가격 민감도 지표 · 수익 보장 아님
