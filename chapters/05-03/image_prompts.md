# 05-03 이미지 생성 프롬프트

## 공통 기준

- 모든 컷에 승인 캐릭터 이미지 `chapters/14/014.png`를 참조한다.
- 누나: 긴 검은 머리 낮은 포니테일, 베이지 재킷, 검은 상의, 넓은 갈색 바지.
- 남자 친구: 키가 작고 통통한 체형, 뾰족한 검은 머리, 주황색 맨투맨, 어두운 카고 바지.
- 여자 친구: 짧은 검은 단발, 주근깨, 크림색 상의, 청록색 멜빵바지.
- 따뜻한 손그림 선화와 단순한 채색. 세로 2:3, 모바일 가독성 우선.
- 컷 001만 제목을 쓴다. 챕터/회차 번호·반복 시리즈 제목·워터마크는 넣지 않는다.
- 한글과 숫자는 아래 대본을 정확히 사용하고, 지정되지 않은 문구는 만들지 않는다.

## 컷별 핵심 요소

001 제목 “채권 분류는 여러 기준으로 본다”. 대화: “이 채권은 회사채니까 이표채인 거지?” / “회사채는 발행주체 기준이고, 이표채는 이자 지급 방식 기준이야.” 여러 분류 렌즈를 한 화면에.
002 세 기간 구간과 교재 상품 예시를 정확히 표기. 단기 ≤1년, 중기 1년 초과~10년, 장기 10년 초과. 하단 “교재의 분류 예시”.
003 보증채/무보증채, 담보채/무담보채, 선순위채/후순위채를 세 개의 독립된 짝으로 보여 준다. 세 축을 섞지 않는다.
004 고정금리채와 변동금리채(FRN) 비교. “기준금리 + 가산금리”, 예시 “LIBOR + 0.2%”, “CD 수익률 + 0.5%”, “교재에 실린 예시”.
005 역변동금리채 수식 “7% − CD 수익률”. 기준금리 상승 화살표와 이자율 하락 화살표를 보여 주고 교재 예시라고 표시.
006 이자율 재설정은 정해진 주기에 이루어짐을 표현. “가격 변동이 없다”고 쓰지 않는다. 가격 민감도가 상대적으로 낮을 수 있다고 설명.
007 만기일시상환채와 이표채의 중간 현금흐름 차이를 비교한다. 발행주체 분류와 혼동하지 않는다.
008 투자적격 “AAA, AA, A, BBB”; 투기 “BB, B, CCC, CC, C, D”; 회사채 최하위 투자적격 “BBB”; 기업어음 “A3까지”. 등급은 보장이 아니라는 짧은 주의문.
009 네 카드: “회사채=발행주체”, “이표채=이자지급”, “변동금리채=금리구조”, “BBB=신용등급”. 여러 축을 혼합하지 않는다.
010 체크리스트 6축: 만기 / 보증·담보 / 변제순위 / 금리 고정 여부 / 중간 현금흐름 / 신용등급. 마무리 대사 “어떤 기준으로 묻는지 먼저 확인할게.”
