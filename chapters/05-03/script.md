# 05-03 채권의 분류와 종류 (3): 기타의 분류

## 학습 목표

채권은 만기, 보증, 담보, 변제순위, 이자율 구조, 신용도처럼 서로 다른 기준으로 분류될 수 있음을 이해한다. 하나의 채권이 여러 분류 기준에 동시에 해당할 수 있다는 점을 사례로 익힌다.

## 세로 스크롤 대본

### 05-03-001.png — 채권 분류표가 여러 개인 이유

- 원전: 인쇄 p.257 / PDF 물리 p.1114
- 남자 친구: “이 채권은 회사채니까 이표채인 거지?”
- 누나: “회사채는 발행주체 기준이고, 이표채는 이자 지급 방식 기준이야. 분류 기준이 달라.”
- 화면: 발행주체·만기·보증/담보·변제순위·금리구조·신용등급이라는 여러 분류 렌즈를 보여 준다.

### 05-03-002.png — 만기로 나누기

- 원전: 인쇄 p.257 / PDF 물리 p.1114
- 단기채: 만기 1년 이하 / 중기채: 1년 초과 10년 이하 / 장기채: 10년 초과.
- 교재 표의 예시를 각각 표시한다: 통안증권·만기 1년 금융채 / 대부분의 회사채·금융채, 국민주택채권 1종(5년), 지역개발공채 / 국고채 장기물, 국민주택채권 2종(20년).
- 누나: “이 기간 구분과 상품은 이 교재의 분류 예시야.”

### 05-03-003.png — 보증·담보·변제순위는 다른 질문

- 원전: 인쇄 p.257 / PDF 물리 p.1114
- 보증 여부: 보증채·무보증채. 담보 제공 여부: 담보채·무담보채. 지급순위: 선순위채·후순위채.
- 여자 친구: “보증이 있는지, 담보가 있는지, 상환 순서가 어떤지는 각각 따로 보는구나.”
- 주의: 상대적 안전성은 발행자·계약조건 등 다른 요인도 함께 고려해야 한다.

### 05-03-004.png — 고정금리와 변동금리

- 원전: 인쇄 p.257 / PDF 물리 p.1114
- 고정금리채: 약정된 이자율이 고정. 변동금리채(FRN): 기준금리에 가산금리를 더해 정기적으로 이자율을 조정.
- 교재 예시: “LIBOR + 0.2%” 또는 “CD 수익률 + 0.5%”.
- 화면에 “교재에 실린 예시”를 표시하고 현행 기준금리 안내처럼 표현하지 않는다.

### 05-03-005.png — 역변동금리채는 반대로 움직인다

- 원전: 인쇄 p.257–258 / PDF 물리 p.1114–1115
- 교재 예시: 역변동금리채 이자율 = “7% − CD 수익률”.
- 남자 친구: “기준금리가 오르면 받는 이자는 줄어들 수 있겠네!”
- 누나: “맞아. 교재 예시의 역변동 구조에서는 기준금리가 오를수록 약정 이자율이 낮아져.”
- 일반 변동금리채와 역변동금리채의 방향을 화살표로 비교한다.

### 05-03-006.png — 이자는 언제 조정될까

- 원전: 인쇄 p.258 / PDF 물리 p.1115
- 질문: 시장금리가 움직일 때 변동금리채의 이자율과 가격은 어떻게 될까?
- 설명: 변동금리채는 기준금리가 매 순간 바뀔 때마다 이자율을 즉시 바꾸는 것이 아니라 약정된 조정 시점에 재설정한다. 이 때문에 교재 해설은 일반 채권보다 시장이자율 변화에 덜 민감할 수 있다고 설명한다.
- 남자 친구: “금리를 따라 조정하니까 가격이 덜 민감할 수 있구나.”
- 주의: ‘가격 변동이 없다’고 단정하지 않는다.

### 05-03-007.png — 중간 현금흐름 기준도 있다

- 원전: 인쇄 p.257 / PDF 물리 p.1114
- 만기일시상환채: 복리채·단리채·할인채처럼 원금 상환을 만기에 모으는 유형. 이표채: 정기 이자를 지급.
- 누나: “이건 이자지급·상환 흐름 기준이라 발행주체나 금리구조와 함께 적용할 수 있어.”

### 05-03-008.png — 신용등급은 상환능력의 구간표

- 원전: 인쇄 p.257 / PDF 물리 p.1114
- 투자적격 등급: AAA, AA, A, BBB. 투기 등급: BB, B, CCC, CC, C, D. 세부 등급은 +, 0, −로 나뉠 수 있다.
- 교재 기준 회사채 투자적격 최하위는 BBB. 기업어음은 A3까지 투자적격으로 구분하며, 교재는 회사채 BBB와 대응시킨다.
- 주의: 신용등급은 위험을 요약하는 평가이며 원금상환을 보장하지 않는다.

### 05-03-009.png — 회사채는 분류 기준 하나가 아니다

- 원전: 인쇄 pp.257–258 / PDF 물리 pp.1114–1115
- 예시 카드: “회사채”는 발행주체 기준, “이표채”는 이자지급 기준, “변동금리채”는 금리구조 기준, “BBB”는 신용등급 기준.
- 여자 친구: “한 채권을 여러 기준으로 동시에 설명할 수 있겠네.”
- 원전 보충문제의 정답을 재현하는 대신, 분류축을 구별하는 새 설명 사례로 구성한다.

### 05-03-010.png — 질문을 바꿔 분류하기

- 원전: 인쇄 pp.257–258 / PDF 물리 pp.1114–1115
- 정리 카드: 만기 / 보증·담보 / 변제순위 / 금리 고정 여부 / 중간 현금흐름 / 신용등급.
- 남자 친구: “채권 이름 하나만 보지 말고, 어떤 기준으로 묻는지 먼저 확인할게.”
- 핵심: 서로 다른 분류축은 서로 대체하지 않으며 하나의 채권에 함께 적용될 수 있다.

## 원전 연결

투자자산운용사 제3과목 제5장 Topic 03, 인쇄 pp.257–258 (PDF 물리 pp.1114–1115). 원전의 표·본문·보충문제 해설을 확인했다. 예시 기준과 현재의 상품 현황을 혼동하지 않도록 교재 예시는 해당 판본의 예시로 표시한다.
