# 05-06 발행시장(Primary Market)

## 학습 목표

발행시장의 참여자·발행방식·미매각 위험 부담·입찰금리 결정방식을 구분한다.

## 이야기 갈등

남자 친구는 채권을 처음 사는 거래와 이미 나온 채권 거래를 혼동한다. 누나와 여자 친구가 자금 흐름과 발행 조건을 짚어 준다.

## 원전 확인

`책_투자자산운용사_p1476.pdf` 인쇄 pp.265–267/PDF 물리 pp.1123–1126. 물리 pp.1123–1124는 인쇄 p.265의 동일한 중복 스캔이다. 인쇄 p.266은 물리 p.1125, 인쇄 p.267은 물리 p.1126에서 확인했다. 법규·시장관행은 교재 기준으로 표시하며 현재 제도 전반을 확정하지 않는다.

### 05-06-001.png — 채권은 처음에 어디서 살까?
- 원전: 인쇄 p.265 / PDF 물리 p.1123
- 장면: 카페에서 새 공장을 짓는 회사의 채권 발행 안내를 보는 세 사람. 제목은 첫 컷에만.
- 남자 친구: 채권도 누군가 처음 파는 순간이 있겠네?
- 누나: 새 채권을 발행해 투자자에게 자금을 모으는 곳이 발행시장이야.
- 여자 친구: 이미 나온 채권을 되파는 거래와는 구분하자.

### 05-06-002.png — 돈과 채권은 반대로 움직인다
- 원전: 인쇄 p.265 / PDF 물리 p.1123
- 장면: 발행자와 투자자를 양쪽에 두고 반대 방향 화살표 두 개. 발행기관은 위쪽에서 중개.
- 발행자 → 투자자: 새 채권
- 투자자 → 발행자: 투자대금
- 발행기관: 발행 중개
- 누나: 발행자는 빌리고, 투자자는 자금을 제공해.
- 하단 개념: 장기자금 조달 / 통안증권을 통한 통화조절

### 05-06-003.png — 사모와 공모, 누구에게 권할까?
- 원전: 인쇄 pp.265–266 / PDF 물리 pp.1123,1125
- 장면: 소수와 협의하는 방과 공개 모집 안내를 대비. 교재 설명임을 표시.
- 사모발행: 소수 투자자와 사적 교섭
- 공모발행: 다수에게 청약 권유
- 누나: 교재는 공모를 청약권유대상자 50인 이상으로 설명해.
- 여자 친구: 실제 판단은 적용 법규와 예외도 확인해야겠네.

### 05-06-004.png — 직접발행과 매출발행
- 원전: 인쇄 pp.265–266 / PDF 물리 pp.1123,1125
- 장면: 직접발행과 간접발행을 비교한 뒤, 매출발행의 판매 누적을 금액 없이 시각화.
- 직접발행: 발행자가 직접 모집
- 간접발행: 발행중개기관이 개입
- 매출발행: 일정 기간 팔린 금액이 발행총액
- 남자 친구: 처음부터 발행총액을 정하지 않는 방식도 있구나.
- 교재 기준: 국공채는 매출발행 가능 / 회사채는 매출발행 불가

### 05-06-005.png — 안 팔린 채권은 누가 맡을까?
- 원전: 인쇄 p.266 / PDF 물리 p.1125
- 장면: 세로 세 장면으로 위탁모집·잔액인수·총액인수의 미매각 부담을 비교. 투자손실과 혼동 금지.
- 위탁모집: 모집만 주선 · 발행위험은 발행자 부담
- 잔액인수: 팔리지 않은 잔액을 인수
- 총액인수: 전체를 먼저 인수한 뒤 투자자에게 판매
- 누나: 여기서 발행위험은 모집이 덜 될 위험이야.
- 교재 설명: 무보증사채는 주로 총액인수

### 05-06-006.png — 입찰은 낮은 금리부터
- 원전: 인쇄 pp.266–267 / PDF 물리 pp.1125–1126
- 장면: 입찰금리 표를 교재 예시로 제시. A~F만 낙찰, G 탈락. 숫자 정확하게.
- 교재 예시 · 발행액 1,000억 원
- A 3.50% 100억 / B 3.60% 200억
- C 3.70% 250억 / D 3.80% 150억
- E 3.90% 200억 / F 4.00% 100억
- G 4.05% 300억 → 낙찰 실패
- 누나: 낮은 입찰금리부터 채우면 A부터 F까지 합계 1,000억 원이야.

### 05-06-007.png — 같이 낙찰돼도 적용 금리는 다르다
- 원전: 인쇄 pp.266–267 / PDF 물리 pp.1125–1126
- 장면: 교재 예시의 Conventional과 Dutch 적용금리를 두 비교판에 표시.
- Conventional · 복수가 낙찰
- 각자 제시한 낙찰금리를 적용
- A 3.50% / B 3.60% / C 3.70%
- D 3.80% / E 3.90% / F 4.00%
- Dutch · 단일가 낙찰
- 낙찰자 A~F 모두 4.00%
- 여자 친구: Dutch는 낙찰금리 중 가장 높은 금리로 통일하네.
- 교재 예시

### 05-06-008.png — 구간별로 섞는 차등가격낙찰
- 원전: 인쇄 pp.266–267 / PDF 물리 pp.1125–1126
- 장면: 교재 예시 세 구간을 서로 다른 색으로 묶음. 표 안에는 적용금리만.
- 차등가격낙찰 · 교재 예시
- A·B → 3.60%
- C·D → 3.80%
- E·F → 4.00%
- 누나: 두 방식을 절충해 구간별로 금리를 다르게 적용해.
- 남자 친구: 낙찰되는 순서와 적용금리를 나눠 봐야겠네.

### 05-06-009.png — 국채와 통안증권은 어떻게 발행할까?
- 원전: 인쇄 pp.266–267 / PDF 물리 pp.1125–1126
- 장면: 국채 발행 세 방식과 한국은행 통안증권 방식을 교재 기준 카드로 나눔.
- 교재 기준 · 채권별 발행방식
- 국채: 경쟁입찰 / 첨가소화 / 교부발행
- 국고채권 등 → 경쟁입찰
- 국민주택채권 등 → 첨가소화
- 공공용지 보상채권 등 → 교부발행
- 한국은행 통안증권: Dutch / 매출발행
- 누나: 채권 종류에 따라 발행방식도 달라.

### 05-06-010.png — 같은 종목으로 이어 발행하는 이유
- 원전: 인쇄 pp.266–267 / PDF 물리 pp.1125–1126
- 장면: 동일 만기·표면금리의 국채가 같은 묶음으로 합쳐지고 거래가 활발해지는 모습. 마지막 세 사람 대화.
- 국채통합발행제도
- 만기·표면금리 등 조건을 맞춰 같은 종목을 이어 발행
- 거래량·유동성 증가 → 지표채권 육성
- 국채 발행비용 절감 기대
- 여자 친구: 발행은 돈을 모으는 방식과 위험을 나누는 설계구나.
- 누나: 다음에는 발행된 채권이 거래되는 유통시장을 보자.
