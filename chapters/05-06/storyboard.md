# 05-06 세로 스크롤 콘티

01. 채권은 처음에 어디서 살까?
카페에서 새 공장을 짓는 회사의 채권 발행 안내를 보는 세 사람. 제목은 첫 컷에만.
원전: 인쇄 p.265 / PDF 물리 p.1123

02. 돈과 채권은 반대로 움직인다
발행자와 투자자를 양쪽에 두고 반대 방향 화살표 두 개. 발행기관은 위쪽에서 중개.
원전: 인쇄 p.265 / PDF 물리 p.1123

03. 사모와 공모, 누구에게 권할까?
소수와 협의하는 방과 공개 모집 안내를 대비. 교재 설명임을 표시.
원전: 인쇄 pp.265–266 / PDF 물리 pp.1123,1125

04. 직접발행과 매출발행
직접발행과 간접발행을 비교한 뒤, 매출발행의 판매 누적을 금액 없이 시각화.
원전: 인쇄 pp.265–266 / PDF 물리 pp.1123,1125

05. 안 팔린 채권은 누가 맡을까?
세로 세 장면으로 위탁모집·잔액인수·총액인수의 미매각 부담을 비교. 투자손실과 혼동 금지.
원전: 인쇄 p.266 / PDF 물리 p.1125

06. 입찰은 낮은 금리부터
입찰금리 표를 교재 예시로 제시. A~F만 낙찰, G 탈락. 숫자 정확하게.
원전: 인쇄 pp.266–267 / PDF 물리 pp.1125–1126

07. 같이 낙찰돼도 적용 금리는 다르다
교재 예시의 Conventional과 Dutch 적용금리를 두 비교판에 표시.
원전: 인쇄 pp.266–267 / PDF 물리 pp.1125–1126

08. 구간별로 섞는 차등가격낙찰
교재 예시 세 구간을 서로 다른 색으로 묶음. 표 안에는 적용금리만.
원전: 인쇄 pp.266–267 / PDF 물리 pp.1125–1126

09. 국채와 통안증권은 어떻게 발행할까?
국채 발행 세 방식과 한국은행 통안증권 방식을 교재 기준 카드로 나눔.
원전: 인쇄 pp.266–267 / PDF 물리 pp.1125–1126

10. 같은 종목으로 이어 발행하는 이유
동일 만기·표면금리의 국채가 같은 묶음으로 합쳐지고 거래가 활발해지는 모습. 마지막 세 사람 대화.
원전: 인쇄 pp.266–267 / PDF 물리 pp.1125–1126
