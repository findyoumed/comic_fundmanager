# 05-08 원전·계산 대조

## 원전 범위

2026-11-14 `책_투자자산운용사_p1476.pdf`의 물리 p.1129(인쇄 p.270), p.1131(p.271)을 각각 시각 확인했다. 물리 pp.1129–1130은 렌더 픽셀이 동일한 중복 스캔이다.

## 수식 검토

- 복리채 만기금액: S=F(1+c)^T. c는 표면금리, T는 발행부터 만기까지의 전체 연수다.
- 관행적 복할인: P=S/[(1+y)^n(1+y d/365)]. n과 d는 잔존기간, y는 YTM이다.
- 이론적 복할인: P=S/(1+y)^(n+d/365). 관행적 방식의 단수기간 단리와 혼동하지 않는다.
- 할인채는 S=액면금액이다. 교재 예제의 표면금리 4%를 가격식에 넣지 않는다.
- 이표채는 각 쿠폰과 원금을 지급 시점별로 할인하여 합한다. 연금현가계수 식의 할인율도 YTM이다. 교재 참고 상자의 % 설명은 표면금리로 되어 있으나, 해당 예제의 분모는 YTM 4%다. 만화에서는 y=YTM으로 명확히 적는다.
