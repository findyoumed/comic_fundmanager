# 05-08 채권가격계산

## 학습 목표

현금흐름과 시점을 구분하여 만기일시상환채·할인채·이표채의 현재가치를 계산하고 표면금리와 만기수익률의 쓰임을 구별한다.

## 이야기 갈등

만기에 받을 금액이 곧 오늘 가격이라고 생각한 남자 친구가 현금흐름의 시점과 할인율을 나누어 계산한다.

## 원전 확인

2026-11-14 원전 물리 pp.1129,1131을 시각 확인하고 pp.1129–1130의 동일 렌더 픽셀을 확인했다. 할인채·복리채·이표채 계산식과 원전 예제 조건을 대조하고 Decimal로 재계산했다. 원전 이표채의 10,555.01원은 반올림한 중간 항들의 합이며 정밀 계산 후 최종 반올림과 0.01원 차이가 있어 기준을 표시한다. 참고 상자의 %는 표면금리로 표기되어 있지만 할인계수에는 예제처럼 만기수익률을 사용하도록 구분한다.

### 05-08-001.png — 미래에 받을 돈, 오늘은 얼마일까?
- 원전: 인쇄 p.270 / PDF 물리 pp.1129–1130(중복); 인쇄 p.271 / PDF 물리 p.1131
- 장면: 카페에서 남자 친구가 만기 금액을 곧바로 오늘 가격으로 착각한다. 누나가 미래의 현금흐름을 오늘로 가져오는 다리를 그린다.
- 남자 친구: “나중에 받을 돈이 채권 가격인 거 아니야?”
- 누나: “언제 얼마를 받는지 먼저 보고, 그 돈을 현재가치로 할인해야 해.”
- 여자 친구: “약정 이자를 정하는 금리와 할인에 쓰는 금리는 구분하자.”
- 표시 문구: 표면금리: 약정 현금흐름 계산
- 표시 문구: 만기수익률: 현재가치 할인

### 05-08-002.png — 만기에 한 번 받는 채권부터
- 원전: 인쇄 p.270 / PDF 물리 pp.1129–1130(중복)
- 장면: 하나의 만기 현금흐름 S만 있는 시간선. 연단위 복리채의 만기금액을 액면과 표면금리로 구한다.
- 누나: “연단위 복리채는 이자가 쌓인 만기금액 S를 먼저 구해.”
- 표시 문구: F: 액면금액
- 표시 문구: c: 표면금리
- 표시 문구: T: 발행부터 만기까지 전체 연수
- 표시 문구: S = F × (1+c)^T
- 표시 문구: 할인채는 만기에 액면금액 F를 받음

### 05-08-003.png — 잔존기간은 정수 연수와 남은 일수로
- 원전: 인쇄 p.270 / PDF 물리 pp.1129–1130(중복)
- 장면: 오늘부터 만기까지 n년과 d일로 구분된 시간선. 위에는 관행적 복할인, 아래에는 이론적 복할인의 분모를 비교한다.
- 여자 친구: “분자는 받을 돈, 분모는 남은 기간의 할인 방식이네.”
- 표시 문구: y = 만기수익률(YTM)
- 표시 문구: 잔존기간: n년 + d일 · 1년=365일
- 표시 문구: 관행적 복할인
- 표시 문구: P = S ÷ [(1+y)^n × (1+y×d/365)]
- 표시 문구: 이론적 복할인
- 표시 문구: P = S ÷ (1+y)^(n+d/365)

### 05-08-004.png — 복리채: 표면금리와 YTM을 바꿔 넣지 말자
- 원전: 인쇄 p.270 / PDF 물리 pp.1129–1130(중복)
- 장면: 교재 예시 조건을 위에 제시하고, 중간에는 만기금액, 아래에는 오늘 가격 계산을 분리한다. 계산값임을 표시.
- 누나: “만기금액에는 표면금리 3%, 할인에는 YTM 5.5%를 써.”
- 표시 문구: 교재 예시 재계산
- 표시 문구: 액면 10,000원 · 표면금리 3%
- 표시 문구: 전체 만기 5년 · 잔존 3년 94일 · YTM 5.5%
- 표시 문구: S = 10,000 × (1.03)^5
- 표시 문구: S = 11,592.740743원
- 표시 문구: P = S ÷ [(1.055)^3 × (1+0.055×94/365)]
- 표시 문구: P ≈ 9,734.65원

### 05-08-005.png — 할인채: 만기에는 액면을 받는다
- 원전: 인쇄 p.270 / PDF 물리 pp.1129–1130(중복)
- 장면: 한 번의 10,000원 만기 현금흐름과 두 잔존기간 사례를 비교. 표면금리 4% 입력카드는 할인채 계산식에서 제외하는 모습을 보여준다.
- 남자 친구: “할인채에는 표면금리 4%를 곱하지 않는구나.”
- 표시 문구: 교재 예시 재계산 · YTM 5% · 1년=365일
- 표시 문구: 잔존 91일
- 표시 문구: P = 10,000 ÷ (1+0.05×91/365)
- 표시 문구: P ≈ 9,876.88원
- 표시 문구: 잔존 1년 91일
- 표시 문구: P = 10,000 ÷ [1.05×(1+0.05×91/365)]
- 표시 문구: P ≈ 9,406.55원
- 표시 문구: 계산값은 소수 둘째 자리 반올림

### 05-08-006.png — 이표채는 받을 돈이 여러 번

- 장면: 발행일 매입, 연 1회 후급 이표채 시간선. 연말 1·2·3 시점의 현금흐름을 정확히 표시하고 마지막 원금과 쿠폰을 색으로 분리.
- 누나: “표면금리 6%라서 매년 쿠폰은 600원이야. 마지막에는 원금도 더해.”
- 표시 문구: 교재 예시
- 표시 문구: 액면 10,000원 · 표면금리 6% · 만기 3년
- 표시 문구: 발행일 매입 · 연 1회 후급 · YTM 4%
- 표시 문구: 1년 말: 600원
- 표시 문구: 2년 말: 600원
- 표시 문구: 3년 말: 10,600원 = 원금 10,000원 + 쿠폰 600원

### 05-08-007.png — 각 현금흐름을 따로 할인한다
- 원전: 인쇄 p.271 / PDF 물리 p.1131
- 장면: 세 개 미래 현금흐름 각각에서 오늘로 돌아오는 할인 화살표. 세 현재가치를 큰 산식 카드로 세로 배열한다.
- 여자 친구: “받는 시점이 달라서 할인 횟수도 다르네.”
- 표시 문구: 교재 예시 · 할인율은 YTM 4%
- 표시 문구: 1년 말: 600 ÷ (1.04)^1 ≈ 576.92원
- 표시 문구: 2년 말: 600 ÷ (1.04)^2 ≈ 554.73원
- 표시 문구: 3년 말: 10,600 ÷ (1.04)^3 ≈ 9,423.36원

### 05-08-008.png — 가격은 현재가치를 더한 값
- 원전: 인쇄 p.271 / PDF 물리 p.1131
- 장면: 세 할인 금액이 오늘 가격 상자로 모인다. 반올림된 항을 합산하는 교재 방식과 정밀 계산 차이를 작은 별도 메모로 분리.
- 남자 친구: “미래 금액을 그냥 더하는 게 아니라, 할인한 금액을 더하는 거네.”
- 표시 문구: 교재 방식: 각 항을 소수 둘째 자리로 반올림 후 합산
- 표시 문구: 576.92 + 554.73 + 9,423.36
- 표시 문구: P = 10,555.01원
- 표시 문구: 계산 참고: 정밀 계산 후 최종 반올림은 10,555.02원
- 표시 문구: 0.01원 차이는 반올림 시점의 차이

### 05-08-009.png — 연금현가계수로 묶어도 같은 원리
- 원전: 인쇄 p.271 / PDF 물리 p.1131
- 장면: 동일 쿠폰 묶음과 마지막 액면금액을 분리한 뒤 PVIFA·PVIF 식을 세로로 보여준다. 할인율 y를 강조한다.
- 누나: “같은 쿠폰이 반복되면 연금현가계수로 묶을 수도 있어. 할인율은 y야.”
- 표시 문구: 연 1회 후급 · 정수 잔존기간 n
- 표시 문구: C: 매회 쿠폰 · F: 액면금액 · y: YTM
- 표시 문구: P = C×PVIFA(y,n) + F×PVIF(y,n)
- 표시 문구: PVIF(y,n) = 1/(1+y)^n
- 표시 문구: PVIFA(y,n) = [1−(1+y)^(-n)]/y
- 표시 문구: 단위와 지급 주기를 일치시킨다

### 05-08-010.png — 현금흐름부터, 할인은 그다음
- 원전: 인쇄 p.270 / PDF 물리 pp.1129–1130(중복); 인쇄 p.271 / PDF 물리 p.1131

- 여자 친구: “받을 돈의 크기는 표면금리로, 오늘의 가치는 YTM으로 계산하자.”
