# 05-09 채권수익률의 종류와 계산

## 학습 목표

경상수익률, 간이 만기수익률, 실효 연수익률의 분자·분모와 가정을 구분하고 가격이 오를 때 경상수익률이 낮아지는 이유를 설명한다.

## 이야기 갈등

쿠폰이 같으면 채권 수익률도 같다고 생각한 친구가 매입가격과 재투자 조건을 살펴본다.

## 원전 확인

2026-11-15 p1192 물리 pp.919–920 확대 렌더로 직접 확인. 경상수익률 C/P, 만기수익률(YTM)의 간이법, 복리의 실효 연수익률을 구분한다. 인쇄 p.272 핵심문제의 조건은 액면 10,000원·표면이율 8%·만기 3년·시장가격 9,600원이고 묻는 값은 경상수익률이다. 연 이자 800원을 현재 가격 9,600원으로 나누어 약 8.33%다. 인쇄 p.273 보충 예제의 액면 10,000원·4년·쿠폰 6%·가격 9,200원 간이 YTM은 [600+(10,000−9,200)/4]/[(10,000+9,200)/2]=800/9,600=8.33%다. 이 값은 간이법 추정치다. 분기 이율 2%의 연 실효수익률은 (1+0.08/4)^4−1≈8.24%이며 단순 연환산 8%와 구분한다. 원전 선택지를 그대로 복제하지 않는다.

### 05-09-002.png — 경상수익률은 연 이자 나누기 현재 가격
- 원전: 인쇄 p.272 / PDF 물리 p.919
- 장면: 연간 쿠폰 C가 현재 채권가격 P로 나뉘어 비율이 되는 간단한 도식.
- 여자 친구: “경상수익률은 지금 받는 연 이자를 현재 가격과 비교하는 거네.”
- 표시 문구: 경상수익률 = C ÷ P
- 표시 문구: C: 연 이자지급액
- 표시 문구: P: 현재 채권시장가격

- 남자 친구: “액면 1만 원에 표면이율 8%, 3년 만기고 가격은 9,600원이네.”

- 표시 문구: 액면 10,000원

### 05-09-004.png — 먼저 연간 이자를 구해
- 원전: 인쇄 p.272 / PDF 물리 p.919
- 장면: 액면 10,000원과 표면이율 8% 카드가 계산식으로 연결되어 연간 쿠폰 800원이 된다.
- 누나: “액면과 표면이율로 연간 이자 800원을 구하자.”
- 표시 문구: 10,000 × 8% = 800원/년
- 표시 문구: 연간 이자지급액 C = 800원

### 05-09-005.png — 경상수익률 계산
- 원전: 인쇄 p.272 / PDF 물리 p.919
- 장면: 800원 연 이자 카드를 9,600원 가격 카드로 나누어 경상수익률을 표시한다.
- 여자 친구: “현재 가격으로 나누면 약 8.33%야.”
- 표시 문구: 경상수익률 = 800 ÷ 9,600
- 표시 문구: ≈ 8.33%
- 표시 문구: 연 단위 지표

### 05-09-006.png — 가격이 오르면 경상수익률은 내려가
- 원전: 인쇄 p.272 / PDF 물리 p.919
- 장면: 같은 800원 연 이자 카드가 더 높은 가격으로 나뉘어 더 낮은 C/P를 나타낸다. 수치 대신 방향 화살표를 쓴다.
- 남자 친구: “받는 연 이자가 같아도 채권 가격이 오르면 비율은 낮아지는구나.”
- 표시 문구: 연 이자 C 동일
- 표시 문구: 채권가격 P 상승
- 표시 문구: 경상수익률 C/P 하락

### 05-09-007.png — 간이 만기수익률은 가격 차이도 반영
- 원전: 인쇄 pp.272–273 / PDF 물리 pp.919–920
- 장면: 연 쿠폰과 연평균 가격을 분수로 쌓고, 가격과 액면 차이를 잔존기간으로 나눈 값을 더한다.
- 누나: “간이법은 쿠폰뿐 아니라 만기 때의 가격 차이도 연 단위로 넣어.”
- 표시 문구: 간이 YTM = [C + (F−P)/n] ÷ [(F+P)/2]
- 표시 문구: C: 연 이자 · F: 액면 · P: 현재가격 · n: 만기까지 연수

### 05-09-008.png — 간이법 예제로 계산
- 원전: 인쇄 p.273 / PDF 물리 p.920
- 장면: 별도 예제 카드에서 쿠폰 600원과 연평균 가격 9,600원을 표시하고 간이 YTM을 산출한다.
- 여자 친구: “가격 차이의 연평균분까지 더하면 분자가 800원이야.”
- 표시 문구: 교재 보충 예제 · 액면 10,000원 · 4년
- 표시 문구: 표면금리 6% · 가격 9,200원
- 표시 문구: [600+(10,000−9,200)/4] ÷ [(10,000+9,200)/2]
- 표시 문구: = 800 ÷ 9,600 ≈ 8.33%
- 표시 문구: 간이법 추정치

### 05-09-009.png — 복리라면 실효 연수익률로
- 원전: 인쇄 p.273 / PDF 물리 p.920
- 장면: 한 해를 네 분기로 나누어 분기마다 2%가 복리로 쌓이는 모습을 지수식으로 보여준다.
- 남자 친구: “분기 이율을 네 배 하는 것과 실제 복리 결과는 다르네.”
- 표시 문구: 분기 단위 이율 2%
- 표시 문구: 명목 연이율 i = 8% · m = 4
- 표시 문구: y = (1+i/m)^m − 1
- 표시 문구: (1+0.08/4)^4 − 1 ≈ 8.24%
- 표시 문구: 단순 연환산 8%와 구분
