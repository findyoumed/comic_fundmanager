# 05-10 말킬의 채권가격정리

## 학습 목표

다른 조건이 같다는 전제 아래 말킬의 다섯 정리를 설명하고 수익률 변화에 따른 채권가격 변동의 방향과 비대칭성을 구분한다.

## 이야기 갈등

금리가 1% 움직이면 채권가격도 언제나 같은 비율로 반대로 움직인다고 믿는 친구가 만기와 쿠폰, 가격 곡선을 살펴본다.

## 원전 확인

2026-11-15 p1192 물리 pp.921–922를 확대 렌더로 직접 확인했다. 말킬의 5가지 채권가격정리, 가격변동성의 특성, 듀레이션의 방향 관계를 다룬다. 원전의 핵심은 가격과 수익률의 역관계, 잔존기간이 길수록 동일 수익률 변화에 대한 가격변동폭이 커짐, 그 증가는 잔존기간이 길수록 체감함, 만기가 같을 때 수익률 하락에 따른 가격 상승폭이 같은 폭의 수익률 상승에 따른 가격하락폭보다 큼, 표면이자율이 높을수록 동일 수익률 변화에 대한 가격변동폭이 작아짐이다. 이 관계를 절대 법칙으로 과장하지 않고 다른 조건을 고정한 비교임을 표시한다.

- 남자 친구: “시장수익률이 오르면 채권가격도 오르는 거지?”
- 누나: “채권가격과 수익률은 반대 방향으로 움직여.”

- 표시 문구: 채권가격 ↓ · 수익률 ↑

### 05-10-002.png — 잔존기간이 길면 가격 민감도가 커져
- 원전: 인쇄 p.274 / PDF 물리 p.921
- 장면: 같은 크기의 수익률 변화 화살표에 짧은 잔존기간 채권과 긴 잔존기간 채권의 가격 반응 막대 길이를 비교한다.
- 여자 친구: “같은 수익률 변화라면 만기가 더 남은 쪽이 가격이 더 크게 움직이는구나.”
- 표시 문구: 동일한 수익률 변화
- 표시 문구: 잔존기간 짧음: 가격변동폭 작음
- 표시 문구: 잔존기간 김: 가격변동폭 큼

### 05-10-003.png — 기간이 늘수록 증가폭은 체감
- 원전: 인쇄 p.274 / PDF 물리 p.921
- 장면: 잔존기간 축을 따라 가격변동성 곡선이 올라가지만 점점 완만해지는 모양으로 그린다.
- 누나: “변동성은 커지지만, 만기가 길어질수록 늘어나는 폭은 점점 완만해져.”
- 표시 문구: 잔존기간 증가 → 가격변동성 증가
- 표시 문구: 증가폭은 체감
- 표시 문구: 개념도 · 수치 눈금 없음

### 05-10-004.png — 수익률 변화에는 볼록성이 있어
- 원전: 인쇄 p.274 / PDF 물리 p.921
- 장면: 볼록한 가격-수익률 곡선에서 기준점으로부터 같은 폭의 수익률 상승과 하락을 비교한다.
- 여자 친구: “같은 폭이면 수익률 하락 쪽 가격 상승이 더 크네.”
- 표시 문구: 같은 만기 · 같은 크기의 수익률 변화
- 표시 문구: 수익률 하락 → 가격 상승폭 큼
- 표시 문구: 수익률 상승 → 가격 하락폭 작음

### 05-10-005.png — 쿠폰이 높으면 변동폭은 작아
- 원전: 인쇄 p.274 / PDF 물리 p.921
- 장면: 같은 만기와 수익률 변화 조건 아래 낮은 쿠폰 채권의 가격 반응을 큰 막대, 높은 쿠폰 채권을 작은 막대로 비교한다.
- 누나: “다른 조건이 같으면 표면이자율이 높을수록 가격변동폭은 작아.”
- 표시 문구: 동일한 수익률 변화
- 표시 문구: 표면이자율 낮음 → 가격변동폭 큼
- 표시 문구: 표면이자율 높음 → 가격변동폭 작음

### 05-10-006.png — 다섯 정리를 한 번에

- 장면: 다섯 개의 간결한 카드에 말킬의 가격·수익률, 만기, 체감, 볼록성, 쿠폰 관계를 정리한다.
- 남자 친구: “방향, 만기, 쿠폰 조건을 같이 기억해야겠어.”
- 표시 문구: ① 가격과 수익률은 역관계
- 표시 문구: ② 잔존기간이 길수록 변동성 큼
- 표시 문구: ③ 기간이 늘수록 증가폭 체감
- 표시 문구: ④ 수익률 하락 시 상승폭이 더 큼
- 표시 문구: ⑤ 쿠폰이 높을수록 변동성 작음

### 05-10-007.png — 가격 변동성은 듀레이션과 연결돼
- 원전: 인쇄 p.274 / PDF 물리 p.921
- 장면: 가격변동성 카드가 듀레이션 카드와 연결되고, 표면이자율·잔존만기·만기수익률 화살표가 방향을 나타낸다.
- 누나: “말킬 정리에서 보는 가격 민감성은 듀레이션의 성질과 이어져.”
- 표시 문구: 가격변동성(듀레이션) ↑
- 표시 문구: 표면이자율 ↓
- 표시 문구: 잔존만기 ↑
- 표시 문구: 만기수익률 ↓

### 05-10-008.png — 작은 변화와 큰 변화는 달라
- 원전: 인쇄 p.274 / PDF 물리 p.921
- 장면: 작은 수익률 변화 주변의 대칭 근사와 큰 변화에서 드러나는 비대칭 곡선을 나란히 비교한다.
- 여자 친구: “작은 변화는 대략 대칭으로 볼 수 있지만 큰 변화까지 같진 않아.”
- 표시 문구: 작은 수익률 변화: 대략 대칭 근사
- 표시 문구: 큰 수익률 변화: 가격반응 비대칭
- 표시 문구: 실제 관계는 볼록

- 남자 친구: “만기와 쿠폰을 같이 바꾸면 무엇 때문에 차이 났는지 알기 어렵겠네.”

### 05-10-010.png — 방향과 전제를 함께 기억하자
