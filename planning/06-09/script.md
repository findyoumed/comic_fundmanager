# 06-09 옵션기초 — 제작 준비본

원전 대조·대본 준비 상태. 그림·JPG·모바일 검토 미완료.

## 001 — 옵션은 권리
원전: 인쇄 p.330 / 현재 p1195 물리 pp.978–980
친구가 계약이면 반드시 거래해야 한다고 묻는다.누나는 권리와 의무를 두 카드로 구분한다.
누나: 옵션 매수자는 정한 조건으로 거래할 권리를 얻어. 선도의 양쪽 의무와 구별하자.
표시: 기초자산 / 행사가격 K / 행사 가능한 시점

## 002 — 콜과 풋
원전: 인쇄 p.330 / 현재 p1195 물리 pp.978–980
살 권리와 팔 권리를 큰 두 칸으로 그린다.풋 매수의 팔 권리를 옵션 자체의 매도와 섞지 않는다.
여자 친구: 콜은 살 권리, 풋은 팔 권리네. 풋 매수와 옵션 매도는 다른 말이구나.
표시: 콜: 매수할 권리 / 풋: 매도할 권리

## 003 — 유럽형과 미국형
원전: 인쇄 p.330 / 현재 p1195 물리 pp.978–980
같은 만기 달력에 유럽형은 만기 한 점,미국형은 만기 전부터 만기까지 구간으로 표시한다.
누나: 이 이름은 행사 시점의 차이야. 유럽형은 만기에, 미국형은 만기 전에도 행사할 수 있어.
표시: 유럽형: 만기 행사 / 미국형: 만기 이전에도 행사

## 004 — 프리미엄과 발행자의 의무
원전: 인쇄 p.331–332 / 현재 p1195 물리 pp.978–980
매수자에서 매도자로 프리미엄 화살표,매도자 쪽에는 행사 시 계약 이행 의무 표지.
여자 친구: 교재의 기본 모형에서는 매수자는 프리미엄을 내고, 매도자는 받고 의무를 부담하네.
표시: 프리미엄 지급형 기본 모형 / 매수: 프리미엄 지급·권리 / 매도: 프리미엄 수취·이행 의무

## 005 — 콜 매수의 만기손익
원전: 인쇄 p.330–331 / 현재 p1195 물리 pp.978–980
가로축ST,세로축만기손익. K까지−C에서 평평하고 그 뒤 기울기+1로 올라가 K+C에서0을 통과한다.
누나: 권리의 만기 지급액에서 처음 낸 프리미엄을 빼야 손익이야.
표시: 콜 매수: max(S_T−K,0)−C / 최대손실 C / 손익분기점 K+C

## 006 — 콜 매도는 반대
원전: 인쇄 p.331–332 / 현재 p1195 물리 pp.978–980
콜 매수 도표를 0축 대칭으로 뒤집는다.K까지+C,그 뒤 내려가 K+C에서0을 통과한다.
여자 친구: 받은 프리미엄이 최대이익이고, 가격이 계속 오르면 손실은 크게 늘 수 있네.
표시: 콜 매도: C−max(S_T−K,0) / 최대이익 C / 상승 시 손실에 상한이 없는 기본 모형

## 007 — 풋 매수
원전: 인쇄 p.330–331 / 현재 p1195 물리 pp.978–980
ST가낮을때양의손익에서기울기−1로내려가K에서−P가되고그뒤평평.0가격 경계를 표시한다.
누나: 풋은 가격이 하락할 때 권리의 가치가 커져. 이 기본 모형에서 기초자산 가격은 0 이상이야.
표시: 풋 매수: max(K−S_T,0)−P / 최대손실 P / 풋의 이익이 무한대인 것은 아님

## 008 — 풋 매도
원전: 인쇄 p.331–332 / 현재 p1195 물리 pp.978–980
풋 매수손익을0축대칭으로뒤집는다.낮은ST에서손실, K이상은+P로평평하다.
여자 친구: 풋 매도도 콜 매도와 똑같이 무한손실이라고 쓰면 안 되겠네.
표시: 풋 매도: P−max(K−S_T,0) / 최대이익 P / S_T≥0에서 손실은 유한하지만 클 수 있음

## 009 — 위험과 기대를 구별
원전: 인쇄 p.331–332 / 현재 p1195 물리 pp.978–980
상승예상콜매수/풋매도,하락예상풋매수/콜매도 네칸.방향이같아도위험구조가다름을색으로구별한다.
누나: 같은 방향을 예상해도 매수와 매도의 손익 구조는 달라. 프리미엄 한도 손실도 가볍게 볼 수는 없어.
표시: 예상 방향과 위험 구조는 별개 / 동일 계약 양측의 손익은 반대 / 다음: 내재가치와 옵션가격
