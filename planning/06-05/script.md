## 001 — 균형가격은 어떻게 정할까
원전: 인쇄pp.319 / p1476물리pp.1196–1200

표시: 현물환율 S / 선물환율 F / 같은 통화·같은 만기 조건

## 002 — 교재의 금리차 근사식
원전: 인쇄pp.319 / p1476물리pp.1196–1200
원달러표시방향과금리기호를먼저설명하고식한개만크게보여준다.
여자 친구: 원/달러 표시에서 국내금리와 외국금리의 자리를 구별해야겠네.
표시: 원/달러 표시 / r_d: 원화금리 / r_f: 달러금리 / τ: 연 단위 잔존기간 / 교재 근사식: F* ≈ S × [1 + (r_d − r_f) × τ]

## 003 — 가격 비교부터
원전: 인쇄pp.319–320 / p1476물리pp.1196–1200
교재예제조건을한줄씩보여준다.근사균형값과시장값을다른색으로구별한다.
누나: 교재의 근사식으로는 1,224원이야. 주어진 선물환가격 1,230원과 비교해.
표시: 교재 예제: S=1,200원/달러 / 원화금리 4% / 달러금리 2% / 1년 / 교재 근사 균형값 1,224원 / 시장 선물환 1,230원

## 004 — 지금의 현금흐름
원전: 인쇄pp.320 / p1476물리pp.1196–1200

여자 친구: 원화를 빌려 달러를 매입하고 운용하는 흐름이구나.
표시: 교재 예제 / 원화 1,200원 차입 / 달러 1달러 매입·운용 / 1년 후 원화 상환액 1,248원

## 005 — 만기에 받을 달러를 고정
원전: 인쇄pp.320 / p1476물리pp.1196–1200
달러예금이1.02달러가되고처음시점에그1.02달러를선물환매도해받을원화를고정하는타임라인.
누나: 만기에 받을 1.02달러의 환전가격을 선물환 매도로 정하는 거야.
표시: 1달러 × 1.02 = 1.02달러 / 처음에 1.02달러 선물환 매도 / 약정 환율 1,230원/달러

## 006 — 만기 차액 확인
원전: 인쇄pp.320 / p1476물리pp.1196–1200

여자 친구: 교재 가정에서 수취액과 상환액의 차이가 6.6원이네.
표시: 선물환 수취 = 1.02 × 1,230 = 1,254.6원 / 차입 원리금 = 1,200 × 1.04 = 1,248원 / 차액 = 6.6원 / 비용·거래제약 등을 제외한 교재 예제

## 007 — 방향을 이름보다 먼저

## 008 — 보유비용 모형
원전: 인쇄pp.320 / p1476물리pp.1196–1200

여자 친구: 현물을 보유하는 데 드는 비용과 보유 중 받는 혜택이 균형가격에 연결되네.
표시: 선물이론가격 = 현물가격 + 순보유비용 / 차입·보관비용 − 배당·편익수익 / 비용의 금액과 이자율 단위를 구별
