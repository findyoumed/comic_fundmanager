## 001 — 목적부터 구분
원전: 인쇄pp.321 / 현재p1195물리pp.969–972
투기·헤지·차익·스프레드 네카드.친구가수익이난거래는모두차익거래라고오해한다.
누나: 가격 방향의 위험을 감수하는 투기와, 기존 위험을 줄이는 헤지는 목적이 달라.
표시: 투기 / 헤지 / 차익 / 스프레드 / 이 회차: 투기와 헤지

## 002 — 숏 포지션 손익
원전: 인쇄pp.321 / 현재p1195물리pp.969–972
교재의200포인트신규매도→190포인트환매수.가격차·승수·계약수를각칸에놓는다.
여자 친구: 매도한 뒤 가격이 내려가면, 숏 포지션에는 이익이네.
표시: 교재 가정: 200에 10계약 매도 → 190에 환매수 / 승수 50만원/포인트 / (200−190) × 50만원 × 10 = 5,000만원

## 003 — 롱 포지션 손익
원전: 인쇄pp.324 / 현재p1195물리pp.969–972
별도교재예제라는배지와200매수→205전매도.앞의숏과거래를혼합하지않는다.
누나: 반대로 롱은 가격이 오른 뒤 청산하면 이익이야.
표시: 별도 교재 예제: 200에 10계약 매수 → 205에 전매도 / 승수 50만원/포인트 / (205−200) × 50만원 × 10 = 2,500만원

## 004 — 매도헤지와 매수헤지
원전: 인쇄pp.322 / 현재p1195물리pp.969–972
기존현물을보유한쪽과앞으로현물을매입할쪽을나눈다.
여자 친구: 가격하락 위험을 줄이려면 매도헤지, 가격상승 위험을 줄이려면 매수헤지구나.
표시: 기존 현물의 하락위험 → 매도헤지 / 향후 매입의 상승위험 → 매수헤지

## 005 — 베이시스의 정의
원전: 인쇄pp.322 / 현재p1195물리pp.969–972
F와S가같은기초자산·인도조건이라는표시.만기접근하며차이가줄어드는개념도.
누나: 이 교재는 베이시스를 선물가격에서 현물가격을 뺀 값으로 써.
표시: 교재 정의: B = F − S / B > 0: 콘탱고 / B < 0: 백워데이션 / 만기 수렴은 기초자산·결제 조건 등 가정 아래 설명

## 006 — 청산 시점과 베이시스 위험
원전: 인쇄pp.322–324 / 현재p1195물리pp.969–972
만기전청산과만기청산타임라인을나누며기초자산불일치위험은없어졌다고그리지않는다.
여자 친구: 만기 전에 청산하면 그때의 베이시스가 남아 헤지 결과에 영향을 주겠네.
표시: 랜덤 베이시스 헤지: 만기 전 청산 / 제로 베이시스 헤지: 만기 청산 가정 / 모든 위험 제거를 뜻하지 않음

## 007 — 헤지 계약 수의 단위
원전: 인쇄pp.323 / 현재p1195물리pp.969–972
현물100억원과1계약가치200포인트×50만원을나누는워크시트.
누나: 계약 수를 구할 때는 현물 금액을 한 계약의 금액으로 나눠.
표시: 교재 가정: 현물 100억원 / 1계약 금액 = 200포인트 × 50만원 = 1억원 / 단순헤지: 100억원 ÷ 1억원 = 100계약 매도

## 008 — 베타 0.8 예제
원전: 인쇄pp.323 / 현재p1195물리pp.969–972
동일현물금액과승수조건을유지하고베타만0.8로표시한다.
여자 친구: 현물의 시장 민감도가 다르면 단순 계약 수에 베타를 반영하네.
표시: 교재 예제: β=0.8 / N = 100 × 0.8 = 80계약 매도

## 009 — 베타 1.2 예제
원전: 인쇄pp.324 / 현재p1195물리pp.969–972
다른교재보충예제라는배지.β1.2에서120계약으로계산한다.
누나: 보충예제의 베타 1.2라면 같은 금액 조건에서 120계약이야.
표시: 별도 교재 예제: β=1.2 / N = 100 × 1.2 = 120계약 매도 / 현물 보유의 시장위험을 상쇄하는 방향

## 010 — 최소분산 헤지비율
원전: 인쇄pp.323 / 현재p1195물리pp.969–972
분산25와4에서표준편차5와2를구하는과정을먼저보여주고상관0.4를곱한다.
여자 친구: 분산을 그대로 나누면 안 되고 표준편차를 써야겠네.
표시: 교재 예제: 현물 분산 25 / 선물 분산 4 / 표준편차: 5 / 2 / 상관계수 0.4 / h* = ρ × σ_S/σ_F = 0.4 × 5/2 = 1

## 011 — 비율과 계약 수는 달라
원전: 인쇄pp.323 + 편집상 단위 검토 / 현재p1195물리pp.969–972
헤지비율1카드와계약수빈칸카드를나란히놓는다.현물노출규모와한계약크기정보가추가됨을아이콘으로표시한다.
누나: 이 계산으로 확인되는 것은 비율이야. 계약 수에는 노출 규모와 한 계약 크기 등 단위 정보도 필요해.
표시: 헤지비율 1 ≠ 언제나 1계약 / 현물 노출·계약 크기·변동성의 측정 단위 확인

## 012 — 헤지의 한계와 다음 전략
원전: 인쇄pp.321–324 / 현재p1195물리pp.969–972
베타헤지·베이시스·거래조건카드를정리한다.고유위험이전부제거된방패금지.

표시: 교재 가정·승수·기간을 확인 / 헤지 효과와 남는 위험을 구별 / 다음: 차익거래
