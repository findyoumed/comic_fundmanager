# 06-02 선도(Forward)거래 — 제작 준비본

그림·JPG·모바일 검토 미완료. 05-18 완료 후 본편 제작.

## 001 — 미래의 거래를 지금 약속
원전: 인쇄pp.312 / p1476물리pp.1188–1189
김치 재료 가격을 걱정하는 여자 친구에게 누나가 생산자와 가공업자의 계약을 설명한다.
누나: 지금 조건을 정하고 미래에 거래하는 약속부터 보자.
표시: 교재 예제 재구성 / 3개월 후 배추 10,000포기 / 포기당 계약가격 3,000원

## 002 — 계약과 시장가격은 달라
원전: 인쇄pp.312 / p1476물리pp.1188–1189
계약가격 카드와 인수도 시점 시장가격 카드를 분리한다.
여자 친구: 교재처럼 인수도 때 시장가격이 5,000원이 되어도 약속한 가격은 3,000원이네.
표시: 계약가격 3,000원 / 인수도 때 시장가격 5,000원

## 003 — 시장가격 대비 계약손익
원전: 인쇄pp.312 / p1476물리pp.1188–1189
계약 매수자·매도자 두 줄을 나란히 보여 같은 차이의 반대 부호를 확인한다.
누나: 시장가격 대비 계약손익은 매수자에게 플러스, 매도자에게 마이너스야.
표시: 포기당 매수자: 5,000 − 3,000 = +2,000원 / 포기당 매도자: 3,000 − 5,000 = −2,000원 / 생산·가공비를 뺀 사업이익과 구별

## 004 — 맞춤형 장외 계약
원전: 인쇄pp.312 / p1476물리pp.1188–1189
수량·가격·인도시점이라는 계약 항목과 당사자 간 약속을 보여준다.
여자 친구: 선도는 선물과 달리 장외에서 조건을 맞춤으로 정할 수 있구나.
표시: 선도: 장외·맞춤형 / 선물: 장내·표준화 / 계약 종류와 거래 장소를 구별

## 005 — 맞춤형의 다른 면
원전: 인쇄pp.312–313 / p1476물리pp.1188–1189
맞춤 계약 서류를 다시 거래하려는 친구와 조건을 비교하는 누나.
누나: 교재는 선도가 표준화되지 않아 유동성이 부족할 수 있다고 설명해.
표시: 선도: 상대매매 / 선물: 경쟁매매 / 선도는 일반적으로 실물인수도

## 006 — 위험을 줄이는 목적
원전: 인쇄pp.313 / p1476물리pp.1188–1189
생산자는 판매대금 예측, 가공업자는 원재료 매입조건 예측이라는 두 말풍선.
여자 친구: 나중 가격을 못 맞혀도 판매·매입 조건을 계획하는 데 도움이 되겠네.
표시: 가격위험 회피 목적 / 이익을 보장하는 계약은 아님

## 007 — 손익이 반대라는 뜻
원전: 인쇄pp.312–313 / p1476물리pp.1188–1189
같은 기초자산의 계약 매수·매도 손익선을 보여주되 가격축과 손익축, 영점에서 같은 손익 크기임을 표시한다.
누나: 같은 계약의 두 쪽 손익은 반대야. 교재는 사후적 제로섬이라고 해.
표시: 같은 계약·같은 수량 / 매수자 계약손익 + 매도자 계약손익 = 0 / 비용 등 제외한 계약손익 비교

## 008 — 약속을 지킬 수 있을까
원전: 인쇄pp.312–313 / p1476물리pp.1188–1189
불리해진 계약의 이행을 걱정하는 친구와 신용위험 카드를 보여주는 누나.
누나: 불리해진 상대방이 약속을 지키지 못할 위험도 봐야 해.
표시: 장외 선도의 상대방 신용위험 / 가격위험을 줄여도 모든 위험이 없어지진 않음 / 다음: 선물거래의 메커니즘
