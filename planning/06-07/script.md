# 06-07 선물거래전략-(2) 차익거래 — 제작 준비본

원전 대조·대본 준비 상태. 그림·JPG·모바일 검토 미완료.

## 001 — 현물과 선물을 함께 비교
원전: 인쇄p.325 / 현재p1195물리973–974
두가격카드와한개의이론가격카드.친구가단순히선물가격이높으면무조건차익이라고묻는다.
누나: 현물과의 단순 차이만 보지 말고, 보유비용을 반영한 이론가격과 비교해야 해.
표시: 현물가격 S / 선물 시장가격 F / 선물 이론가격 F*

## 002 — 고평가된 선물
원전: 인쇄p.325–326 / 현재p1195물리973–974
F>F*판과현물매수/선물매도반대방향의두화살표.
여자 친구: 선물이 이론가격보다 높으면, 교재의 매수차익거래는 현물을 사고 선물을 파는 조합이네.
표시: F > F* / 현물 매수 + 선물 매도 / 매수차익거래 / Cash & Carry

## 003 — 저평가된 선물
원전: 인쇄p.325 / 현재p1195물리973–974
반대경우F<F*에서선물매수와현물매도를정확히뒤집는다.
누나: 반대 괴리라면 거래 방향도 반대야. 현물매도에 필요한 조달 조건도 확인해야 해.
표시: F < F* / 현물 매도 + 선물 매수 / 매도차익거래 / Reverse Cash & Carry

## 004 — 베이시스 두 종류
원전: 인쇄p.325–326 / 현재p1195물리973–974
교재의S100,F105,F*102조건을서로다른칸에배치한다.
여자 친구: 시장 베이시스와 이론 베이시스를 따로 계산해야겠네.
표시: 교재 예제: S=100 / F=105 / F*=102 / 시장 베이시스 = 105−100 = 5포인트 / 이론 베이시스 = 102−100 = 2포인트

## 005 — 금리수익과 알파 구별
원전: 인쇄p.325–326 / 현재p1195물리973–974
높이100·102·105눈금에서100→102구간2,102→105구간3을나누어표시한다.
누나: 교재의 금리수익 구간은 2포인트, 베이시스 차이 수익 알파는 3포인트야.
표시: F*−S = 2포인트: 교재의 금리수익 / α = F−F* = 3포인트 / 보유·금융비용을 빼기 전후를 구별

## 006 — 추가 베이시스 수익은 조건부
원전: 인쇄p.325–326 / 현재p1195물리973–974
교재의금리+α+β카드에서β만예상구간으로점선처리한다.만기전청산시그때의베이시스가영향줌을표시한다.
여자 친구: 추가 베이시스 변화까지 확정 수익이라고 볼 수는 없네.
표시: 교재 표기: 금리 + α + β / β는 향후 베이시스 변화에 따른 추가 요소 / 청산 시점과 거래비용·위험 확인

## 007 — 합성채권의 뜻
원전: 인쇄p.326 / 현재p1195물리973–974
현물매수와선물매도를합친미래현금흐름을보여준다.공정가격조건F=F*배지를분명히표시한다.
누나: 이론가격 조건에서 현물과 선물을 묶어 만기 현금흐름을 고정하는 합성 구조로 설명하는 거야.
표시: 현물 매수 + 선물 매도 / F=F* 등 교재의 이론 조건 구별 / 배당·조달·결제 조건 확인

## 008 — 교재의 절세 서술은 구분
원전: 인쇄p.326 / 현재p1195물리973–974
책갈피에교재절세비교,다른작은판에과세대상·시점·상품조건을적는다.실제세율숫자추가금지.
여자 친구: 교재의 절세 비교만 보고 모든 상황에서 세금이 없다고 읽으면 안 되겠네.
표시: 교재의 합성채권 절세 비교 / 세후 유불리를 확정하지 않음 / 과세 시점·상품·투자자 조건은 별도 확인

## 009 — 한쪽 가격 예측과 구별
원전: 인쇄p.325–326 / 현재p1195물리973–974
현물/선물두포지션의연결을정리한다.다음두선물계약의가격차로관심을옮긴다.
누나: 가격 관계의 괴리를 이용하는 구조와 단순 방향성 거래를 구분하자.
표시: 이론가격·시장가격·비용을 함께 비교 / 다음: 두 선물의 스프레드
