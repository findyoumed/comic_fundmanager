# 06-08 선물거래전략-(3) 스프레드거래 — 제작 준비본

원전 대조·대본 준비 상태. 그림·JPG·모바일 검토 미완료.

## 001 — 스프레드의 기준
원전: 인쇄p.327–329 / 현재p1195물리975–977
두선물만기카드를나란히놓고무엇에서무엇을빼는지먼저정한다.
누나: 이 예제에서는 원월물 가격에서 근월물 가격을 뺀 값을 스프레드로 두자.
표시: 스프레드 D = 원월물 − 근월물 / 절대 가격 방향과 상대 가격차를 구별

## 002 — 상품 내와 상품 간
원전: 인쇄p.327 / 현재p1195물리975–977
같은상품3월물/6월물과다른상품조합이라는두분류판.
여자 친구: 상품은 같고 만기만 다르면 시간스프레드, 상품도 다르면 상품 간 스프레드네.
표시: 상품 내: 교재 예시 3월물·6월물 / 시간스프레드 / Calendar Spread / 상품 간 스프레드

## 003 — 축소 예상 예제
원전: 인쇄p.327 / 현재p1195물리975–977
근월90과원월95의가격차5,정상2라는교재조건을보여준다.
누나: 교재처럼 가격차가 5이고 정상 수준 2로 좁아질 것으로 예상하면 어떻게 할까?
표시: 교재 예제: 근월 90 / 원월 95 / 현재 스프레드 = 5 / 정상 스프레드 = 2

## 004 — 축소에 맞는 두 포지션
원전: 인쇄p.327–329 / 현재p1195물리975–977
근월매수·원월매도화살표를가격카드에정확히배치한다.
여자 친구: 싼 근월물을 사고 비싼 원월물을 파는 축소 포지션이구나.
표시: 근월물 매수 + 원월물 매도 / D 축소 예상 / 회귀가 보장되지는 않음

## 005 — 확대 예상 예제
원전: 인쇄p.328 / 현재p1195물리975–977
별도교재예제3월100/6월102,정상3을표시하고3월매도6월매수의반대포지션.
누나: 별도 예제는 현재 가격차 2가 넓어질 것으로 예상해.
표시: 별도 교재 예제: 3월 100 / 6월 102 / 현재 D=2 / 정상 D=3 / 3월물 매도 + 6월물 매수

## 006 — 청산 손익을 합산
원전: 인쇄p.328 / 현재p1195물리975–977
6월102→110롱8과3월100→105숏−5를나란히합산한다.
여자 친구: 두 계약이 모두 올라도, 원월물이 더 많이 오르면 이 조합은 이익이네.
표시: 교재 청산 예시: 6월물 110 / 3월물 105 / 6월 매수 손익: 110−102 = +8 / 3월 매도 손익: 100−105 = −5 / 합계 +3포인트 = 청산 D5 − 진입 D2

## 007 — 가격차와 매매대금은 달라
원전: 인쇄p.328 + Topic03편집보완 / 현재p1195물리975–977
선물가격차2포인트판과별도증거금/정산판을분리한다.2포인트를현금납부하는그림금지.
누나: 선물의 가격차를 현물처럼 전액 주고받는 매매대금으로 그리면 안 돼. 증거금과 일일정산을 구분하자.
표시: 가격차·손익 포인트 ≠ 계약대금 전액 지급 / 증거금·정산 현금흐름은 별도

## 008 — 강세와 약세의 이름
원전: 인쇄p.328–329 / 현재p1195물리975–977
교재콘탱고가정에서근월상대강세와상대약세의두판.양쪽모두하락가능함을문구로구별한다.
여자 친구: 강세라는 이름도 절대 가격이 아니라 근월물의 상대 움직임을 기준으로 읽어야겠네.
표시: 교재의 콘탱고 가정 / 강세: 근월 매수·원월 매도 → D 축소 / 약세: 근월 매도·원월 매수 → D 확대

## 009 — 옵션 스프레드 용어 예고
원전: 인쇄p.327·329 / 현재p1195물리975–977
원전콜K2001개월매수/2개월매도는수평,콜195매수/200매도는수직이라고판으로비교하되옵션손익선은아직안그린다.
누나: 원전은 옵션의 수평·수직 스프레드도 소개해. 선물의 강세·약세 이름과 그대로 섞지 말자.
표시: 수평: 같은 행사가격·다른 만기 / 수직: 다른 행사가격 / 옵션 강세·약세의 명칭 기준은 별도

## 010 — 무엇이 변해야 이익일까
원전: 인쇄p.327–329 / 현재p1195물리975–977
정의D와두포지션을다시연결하고다음옵션의권리로이야기를잇는다.
여자 친구: 이름부터 외우기보다 가격차의 정의와 두 매매 방향을 확인하겠어.
표시: 정의 → 예상 → 포지션 → 두 손익 합산 / 다음: 옵션기초
