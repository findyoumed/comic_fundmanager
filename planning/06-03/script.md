# 06-03 선물거래 메커니즘 — 제작 준비본

상태: 원전 대조 및 대본 준비. 그림·JPG·모바일 검토는 미완료.

## 001 — 선물의 매수와 매도
원전: 인쇄pp.314·316 / p1476물리pp.1190–1193
계약을 사는 롱, 계약을 파는 숏 카드를 나란히 보여 준다. 두 쪽 모두 증거금 표지와 연결한다.
누나: 선물은 매수와 매도 양쪽 모두 증거금이 필요해.
표시: 롱: 매수 포지션 / 숏: 매도 포지션 / 양쪽 모두 증거금

## 002 — 반대거래로 포지션 정리
원전: 인쇄pp.314–315 / p1476물리pp.1190–1193
롱→전매도,숏→환매수라는 두 화살표. 계약 종류와 신규/청산 여부를 분리한다.
여자 친구: 선물 매도라고 모두 새 숏은 아니네. 기존 롱을 끝내는 매도도 있구나.
표시: 롱 청산: 전매도 / 숏 청산: 환매수 / 만기 전 반대거래

## 003 — 증거금과 일일정산
원전: 인쇄pp.314 / p1476물리pp.1190–1193
하루 단위 달력과 증거금 잔액판. 손익 정산 뒤 잔액이 변한다. 가격 상승/하락 손익 방향을 특정하지 않는 중립도식.
누나: 보유 포지션 손익을 매일 정산하고 증거금 잔액을 확인해.
표시: 일일정산 / 손익 반영 → 잔액 변동 / 결제이행을 위한 증거금

## 004 — 마진콜 예제
원전: 인쇄pp.314 / p1476물리pp.1190–1193
개시1500만원·유지1000만원·현재600만원을 큰 숫자로 분리하고 차이를 계산한다.
남자 친구: 유지증거금까지만이 아니라 예제의 개시증거금까지 채우는 거구나.
표시: 교재 예제 / 개시증거금 1,500만원 / 유지증거금 1,000만원 / 현재 잔액 600만원 / 추가증거금 = 1,500 − 600 = 900만원

## 005 — 계약금액과 증거금은 달라
원전: 인쇄pp.315 / p1476물리pp.1190–1193
한 계약금액과 거래에 필요한 증거금이 다른 개념임을 대조. 교재가정 배지를 식보다 먼저 표시한다.
누나: 교재가 가정한 승수와 증거금률로 계산한 값이야. 현재 거래 규격이라고 외우면 안 돼.
표시: 교재 가정: 지수 200포인트 × 승수 50만원 / 계약금액 = 1억원 / 개시증거금률 15% → 1,500만원 / 계약금액 ≠ 증거금

## 006 — 거래량과 미결제약정
원전: 인쇄pp.315–316 / p1476물리pp.1190–1193
거래횟수 계수기와 아직청산되지않은계약서 묶음을 따로 그린다.
여자 친구: 많이 거래됐다는 사실만으로 미결제약정이 늘었다고 할 수는 없네.
표시: 미결제약정: 아직 청산되지 않은 계약 수 / 거래량과 구별 / 이하 교재 보충문제를 재구성

## 007 — 두 쪽이 모두 신규
원전: 인쇄pp.315–316 / p1476물리pp.1190–1193
투자자A 신규매수와B 신규매도를 잇고 계약1개가 생기는 도식.
누나: 신규 매수와 신규 매도가 만나면 미결제약정은 한 개 늘어.
표시: A 신규매수 ↔ B 신규매도 / 미결제약정 +1 / 예제 누적: 1계약

## 008 — 포지션이 다른 사람에게 넘어가면
원전: 인쇄pp.315–316 / p1476물리pp.1190–1193
첫행C신규매수↔A전매도,둘째행B환매수↔D신규매도. 각각기존계약유지. 숫자증가화살표금지.
여자 친구: 한쪽이 새로 들어오고 다른 쪽이 나가면 미결제약정 수는 그대로네.
표시: C 신규매수 ↔ A 전매도: 변화 없음 / B 환매수 ↔ D 신규매도: 변화 없음 / 예제 누적: 여전히 1계약

## 009 — 두 쪽 모두 청산
원전: 인쇄pp.316 / p1476물리pp.1190–1193
D환매수와C전매도를 연결하고 미결제계약서 한 개를 닫는다.
누나: 두 쪽이 모두 포지션을 청산하면 한 개 줄어.
표시: D 환매수 ↔ C 전매도 / 미결제약정 −1 / 예제 최종: 0계약

## 010 — 거래 장치와 위험을 구별
원전: 인쇄pp.314–316 / p1476물리pp.1190–1193
청산소·증거금·일일정산 세 장치 카드와 시장가격 변동 카드. 초보가 다음회차 경제적기능으로 질문을잇는다.
누나: 이 장치가 있다고 시장가격 변동에 따른 손실까지 없어지는 건 아니야.
표시: 청산소·증거금·일일정산 / 가격변동에 따른 손실 가능 / 다음: 선물거래의 경제적 기능
