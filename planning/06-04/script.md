# 06-04 선물거래의 경제적 기능 — 제작 준비본

원전 대조·대본 준비 상태. 그림·JPG·모바일 검토는 미완료.

## 001 — 선물시장은 어떤 일을 할까
원전: 인쇄pp.317 / p1476물리pp.1194–1195
누나가 지난 회차의 계약 장치를 접고 경제적기능 지도 네 칸을 펼친다.
누나: 계약이 어떻게 작동하는지 봤으니, 시장에서 어떤 역할을 하는지 나눠 보자.
표시: 위험 전가 / 가격 발견 / 효율성 증대 / 거래비용 절감

## 002 — 가격위험을 옮기는 헤지
원전: 인쇄pp.317–318 / p1476물리pp.1194–1195
달러를 받을 수출업자와 달러를 지급할 수입업자를 나란히 보여준다. 방향은 말풍선별로 분리한다.
여자 친구: 달러를 받을 수출업자는 매도헤지, 지급할 수입업자는 매수헤지로 구별하네.
표시: 교재 예시 / 수출업자: 달러 수취 → 매도헤지 / 수입업자: 달러 지급 → 매수헤지

## 003 — 가격 발견
원전: 인쇄pp.317 / p1476물리pp.1194–1195
미래 거래를 바라보는 여러참가자의정보가선물시장가격으로모이는개념도. 미래실현가격과같다고그리지않는다.
누나: 시장의 경쟁으로 형성된 가격에 참가자들의 미래 예상이 반영되는 거야.
표시: 미래 예상과 정보 반영 / 예상은 미래 실현가격의 보장이 아님

## 004 — 차익거래와 효율성
원전: 인쇄pp.317–318 / p1476물리pp.1194–1195
현물가격과선물이론가격관계가어긋난그림에서거래를거쳐괴리가줄어드는개념도. 임의숫자금지.
여자 친구: 교재는 차익거래가 가격 관계의 괴리를 줄이는 기능과 연결된다고 설명하네.
표시: 시장가격과 이론가격의 괴리 / 차익거래 → 괴리 축소 / 효율성 증대

## 005 — 적은 증거금과 거래비용
원전: 인쇄pp.317 / p1476물리pp.1194–1195
계약금액1억원/개시증거금1500만원/15%는교재가정임을큰상단배지로표시한다. 아래기존보유현물과선물매도방식을비교하되수익보장금지.
누나: 교재는 낮은 증거금과 선물매도를 통한 비용상 이점을 들어. 하지만 손실위험이 작다는 뜻은 아니야.
표시: 교재 가정: 계약금액 1억원 / 개시증거금률 15% → 1,500만원 / 현행 상품 규격을 뜻하지 않음

## 006 — 부외거래라는 설명은 구분해서
원전: 인쇄pp.318 + IFRS9 공식 설명 / p1476물리pp.1194–1195
책갈피에는교재서술,다른설명판에는현재기준보완.부외거래단어를삭제하지않고서술과교정분리.
여자 친구: 교재의 부외거래 설명을, 지금도 파생상품은 주석에만 적는다는 뜻으로 읽으면 안 되겠네.
표시: 교재 서술: 부외거래 / 현재 기준 보완: IFRS 9 인식 원칙 / 금융자산·부채 인식과 주석 공시는 구별

## 007 — 콘탱고와 백워데이션
원전: 인쇄pp.318 / p1476물리pp.1194–1195
현재현물가격S와동일시점선물가격F카드의높이를두경우로나눠비교한다.만기별선물곡선으로바꾸지않는다.
누나: 이 교재는 선물가격과 현물가격의 관계로 두 용어를 설명해.
표시: 교재의 비교 기준: 선물 F / 현물 S / F > S: 콘탱고 / F < S: 백워데이션
