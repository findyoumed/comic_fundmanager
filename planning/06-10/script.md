# 06-10 옵션내재가치와 옵션가격 — 제작 준비본

원전 대조·대본 준비 상태. 그림·JPG·모바일 검토 미완료.

## 001 — 내재가치는 무엇일까
원전: 인쇄 p.333·335 / 현재 p1195 물리 pp.981–984
당장 행사할 때의 이득과 옵션을 산 전체손익을 다른 칸으로 분리한다.
누나: 내재가치와 순손익은 달라. 내재가치는 음수가 되지 않도록 0과 비교해.
표시: 콜 IV=max(S−K,0) / 풋 IV=max(K−S,0)

## 002 — 행사가 100, 가격 120
원전: 인쇄 p.333 / 현재 p1195 물리 pp.981–984
교재예제의콜/풋내재가치를두식으로보여준다.프리미엄미차감임을표시한다.
여자 친구: 콜은 20이지만 풋은 −20이 아니라 0이네.
표시: 교재 예제: K=100 / S=120 / 콜 IV=20 / 풋 IV=0 / 프리미엄 차감 전 가치

## 003 — 내가격·등가격·외가격
원전: 인쇄 p.333–334 / 현재 p1195 물리 pp.981–984
콜과풋의관계를반대방향두표로나눈다.ATM은동일.
누나: 콜의 내가격 관계는 풋에서는 반대가 돼.
표시: 콜: S>K 내가격 / S=K 등가격 / S<K 외가격 / 풋: S<K 내가격 / S=K 등가격 / S>K 외가격

## 004 — 가격을 두 부분으로
원전: 인쇄 p.334 / 현재 p1195 물리 pp.981–984
옵션가격을IV와TV두덩어리로 나눠 표시한다.최종손익비교축과혼동하지않는다.
여자 친구: 옵션가격에서 내재가치를 빼면 시간가치를 구할 수 있네.
표시: 옵션가격 = 내재가치 + 시간가치 / TV = 옵션가격 − IV

## 005 — 교재의 세 가격 비교
원전: 인쇄 p.334 / 현재 p1195 물리 pp.981–984
K100콜의S80,100,120표와가격0.09,3.50,20.40을IV/TV열로정확히기재한다.
누나: 교재 표는 내재가치가 0이어도 만기 전 가격이 남을 수 있음을 보여 줘.
표시: 교재 표: 행사가격 100인 콜 / S80: IV0 / TV0.09 / 가격0.09 / S100: IV0 / TV3.50 / 가격3.50 / S120: IV20 / TV0.40 / 가격20.40

## 006 — 시간가치의 비교 조건
원전: 인쇄 p.334·336 / 현재 p1195 물리 pp.981–984
등가격예시를강조하되다른조건동일이라는꼬리표.만기전과만기순간을구별하는달력.
여자 친구: 이 교재의 비교에서는 등가격의 시간가치가 크네. 비교 조건도 같아야겠어.
표시: 교재의 다른 조건 동일한 비교 / 남은 시간과 가격 변화 가능성 / 모든 상품의 무조건적 순위로 일반화하지 않기

## 007 — 콜 시간가치 계산
원전: 인쇄 p.335 / 현재 p1195 물리 pp.981–984
S103 K100 C3.5조건에서 IV3먼저구하고TV0.5계산.
누나: 두 번 나눠 계산하자. 먼저 내재가치, 그다음 시간가치야.
표시: 교재 예제: S103 / K100 / 콜가격3.5 / IV=103−100=3 / TV=3.5−3=0.5포인트

## 008 — 풋 시간가치 계산
원전: 인쇄 p.336 / 현재 p1195 물리 pp.981–984
별도풋예제S253K250P1에서음수−3을0과비교해0으로설정한뒤TV1을계산한다.
여자 친구: 풋 내재가치는 0이라서 이 예제의 가격 1이 전부 시간가치네.
표시: 별도 교재 예제: S253 / K250 / 풋가격1 / IV=max(250−253,0)=0 / TV=1−0=1포인트

## 009 — 손익분기점은 행사 가격과 달라
원전: 인쇄 p.336 / 현재 p1195 물리 pp.981–984
별도콜예제K100C3.만기ST축에서K100과BEP103을다른세로선으로표시한다.
누나: 만기 103에서는 손익이 0이고, 비용을 제외한 이 예제에서 그보다 높아야 이익이야.
표시: 별도 교재 예제: K100 / 매수 프리미엄3 / BEP=100+3=103 / S_T=103: 손익0 / S_T>103: 이익

## 010 — 가치와 손익을 분리해 기억

표시: 가치의 구성과 거래 손익을 구별 / 서로 다른 교재 예제의 수치를 섞지 않기 / 다음: 옵션 방향성 전략
